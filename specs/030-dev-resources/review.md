## 需要人类确认的取舍

| 项目 | 建议 | 直接影响 |
|---|---|---|
| Q-021：开发终端与写作业锁 | 撤回 PTY 存活期一律持锁建议；dev / 交互终端不长期持源码写锁，输入控制权独立 | 允许同项目前后端常驻与编辑；脚本可能并行写，须明确非串行保证边界并批准 ADR-029 |
| Q-022：验证路径 | 设计批准后先 M2-0，node-pty + 原生目录监听 / 对账，真实 macOS 与 built 入口 PoC | PoC 失败回评审；不能默认以命令输出替代交互终端 |
| Q-023：回放存储 | 终端内存 1 MiB；落盘 7 天 / 每终端 10 MiB / 总量 100 MiB，先触发者轮转 | 有限历史，游标过旧明确提示缺失；不保留无限终端输出 |
| Q-024：Git 范围 | 基础结构化操作，pull 仅 ff-only / push 仅当前上游，L2 逐次批准；人工动作独立于 Turn | 不做 force / reset / clean / 删除分支 / 远端编辑，Git 认证沿用主机配置 |
| Q-025：重叠项目根 | 根相同或互为祖先视为同一冲突域；独立 workspace 同样纳入 | 不同 projectId 但共享目录不能并发写；须 PoC 验证协调算法 |
| 文件范围 | 已有 UTF-8 文本编辑，512 KiB 上限；冲突手工合并，关闭脏 Tab 需确认 | 不含文件创建 / 删除 / 重命名、二进制和大文件编辑；草稿不存 localStorage |
| 任务顺序与预估 | 保留原 ID，新增 M2-0 / M2-1b / M2-3b / M2-4b / M2-4c / M2-4d / M2-5b，一次一个 | 不并行启动多个子系统；预计 19–30 工作日，仅供范围讨论 |

2026-11-02 人类指出前后端 dev 应由 Agent 创建项目终端 Tab，草案已纳入此场景。Agent 提供启动 / 有界读取 / 显式停止，同项目用途去重；项目资源已交付后不随 Turn 结束 / 取消。锁例外仍是待评审提案，不能把本次场景反馈当作批准修改宪法 / 冻结 ADR。M3 继续负责服务登记、健康检查与预览。

## 已明确的产品修订（ADR-030）

关闭 / 最小化窗口只隐藏视图；主动关闭终端 Tab 终止其 PTY / 受管进程，失败保留 Tab，其他客户端同步 ended。服务窗口无 Tab，左上筛选 + 服务卡片 / 详情。临时服务由终端控制，服务模块只登记展示 / 预览，源退出自动退登；持久服务由 PM2 管理，AI / 人同后端能力。文件修改结果附可点击文件卡片，预览卡片在 M3 绑定已登记目标。该产品规则已接受，不需反复确认；技术门禁仍独立。

AI 完整终端输入 / 中断 / 人机交接已补 m2-resources §10 技术草案并拆为 M2-4d，新增 A30 / A31；schema 已随 G-Spec-M2 批准，按后续任务实施，不把 start / read / stop 当完整交互完成。

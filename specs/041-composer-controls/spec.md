# M2-19 审批盾牌与上下文圆环

> **当前验收：2026-11-05 人类统一通过全部修改与 M2 / G2，本切片已完成。** 最终状态/范围/遗留边界见[收尾记录](../030-dev-resources/closure.md)。下文原日期的待验收/实施记录保留为历史证据，不再表示当前阻塞。
用户直接要求将输入框三点改为仅选择审批策略的盾牌，依策略改变颜色/图案；上下文用量移到发送按钮左侧的小圆形进度条。依赖M2-18 done；沿用用户仅必要校验/自行界面验收指令。

## 目标与非目标
标准审批为蓝色带勾盾牌，严格审批为橙色警示盾牌，只读为绿色盾牌；按钮accessible name/提示包含策略名，菜单仅三种既有策略。上下文圆环约18px，位于发送/停止左边，不显示常驻文字；悬浮与辅助技术可读tokens及百分比。沿用最近一轮contextTokens与所选模型maxContextTokens，0/无统计为空环并明确无统计，不冒充实时推理计数；比例钳制0–100%，接近上限用warning/danger。
不添加新权限/策略/推理模式，不改后端授权或输入/发送/停止流程，不增大资源浮栏/底部说明。

## 验收
- Given选择任一策略，Then盾牌名称/样式随现有policy更新，菜单无上下文内容，下一轮权限语义不变。
- Given32000/128000，Then圆环25%；无统计时不宣称真实0%；超限钳制100%但提示保留实际用量。
- Given执行中，Then圆环仍位于停止按钮左边，不遮挡/替代按钮，原IME/禁止发送/显式停止规则不变。

## 接口、安全、边界
无API/事件/DB/配置/依赖变化。圆环只呈现已存在的输入用量，盾牌不改变标准/严格/只读的实际权限。图案/文字同时区分，不只靠颜色；浅/深token沿用外围主题。

## 测试
先补组件红测试：策略菜单/切换、圆环比例/未知/超限/停止位置，再实现；相关Composer/Conversation测试、Web类型与改动文件Biome。仅必要校验，不跑全量构建/PTY/E2E，用户自行界面验收。同步旧M1浏览器选择器以免菜单改名产生误报，不降低业务断言。

## 修订（2026-11-25，用户直接要求）

上下文占用不再放在输入框工具栏、发送按钮左侧，而是并入输入框下方那一行用量区右侧：14px 圆环 + `32k / 128k · 25%` 常驻文字，Hint 与辅助技术仍给完整 tokens 与百分比。原圆环位置改放附件按钮（点击打开文件选择），工具栏左侧不再重复该按钮。

比例钳制 0–100%、未知不冒充真实 0%、超限保留实际用量提示、发送 / 停止按钮的顺序与权限语义均不变。用量查询已启用但尚无数据时只显示圆环与文字，不显示「Token 统计加载中…」；新会话不渲染该行，见下一次修订。

测试调整为：`SessionUsageLine.test.tsx` 覆盖圆环比例 / 未知 / 行内位置，`Composer.test.tsx` 断言圆环位于用量行、附件按钮紧邻发送 / 停止。

## 修订（2026-11-25 第二次，用户直接要求）

新会话（草稿，或已建立但还没有任何完成 turn 的会话）不渲染输入框下方用量行：没有可报告的用量时不占位、不显示空环、也不显示 `本轮 0 / 窗口 · 0%`。该行在出现第一条用量后出现——进行中的 `model.usage` 步骤，或 `GET /api/sessions/:id/usage` 报告 `turns > 0`；草稿会话即使残留上一会话的 `modelUsage` 也不显示。`contextUsageInfo` 的“`used === 0` 是真实零”仍保留，只用于请求确实回报 0 输入的情况。

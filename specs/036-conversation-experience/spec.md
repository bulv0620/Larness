# 对话区重构与真实任务计划

2026-11-04 用户审批紧凑预览后明确“就按照这个重构一版先”，批准本规格及 M2-14 → M2-15 顺序。

## 目标
中央单列最大 760px，正文 13px / 1.65；用户右侧灰气泡，助手无气泡/头像。每轮真实说明与工具记录归为可展开过程，完成后显示最终答复，历史说明不丢失。复杂任务有 Agent 创建/更新的可折叠计划。底部依次为小型资源浮栏、待处理审批、输入框；输入框下方没有常驻文字或占位。模型/策略/上下文收进输入菜单。

## 非目标
不增加思考模式、多 Provider、排队、中途注入、通用用户提问工具或 M3 服务能力；现有上下文入口沿用文本引用，不能冒充文件上传。不改变认证、审批策略、资源生命周期、锁、原生依赖或数据迁移。

## 验收场景
- Given 复杂任务，When Agent 调用 update_plan，Then 计划逐次持久化再广播，同轮同 ID 更新；刷新恢复最近步骤，普通问答不生成空计划。
- Given 非法计划（重复 ID、多项 running、超限或非法状态），When 调用，Then VALIDATION_ERROR 且不产生 plan.updated。取消/失败不得自动勾完。
- Given 多次工具与助手说明，When 执行/完成，Then 当前动作可见，历史过程可展开且手动展开状态保留，最终答复不重复，纯问答无空过程。
- Given 审批，When 到达，Then 只有输入框上方面板可操作，消息内是摘要；审批期间草稿可编辑且 Enter 不停止/发送。成功确认才收起，失败保留重试，过期禁用，多个请求逐一处理。
- Given 用户向上阅读，When token/审批/工具到达或输入区变高，Then 保留阅读位置；在底部跟随，回到最新可恢复。
- Given 停止/失败/重连，Then 保留部分输出与真实结果，不伪报成功、不重放副作用。
- Given 桌面/320px 窄屏，Then 正文/长路径不撑宽；资源浮栏桌面约30px高，触屏点击区域44px；无底部提示栏。

## 接口与数据
新增 L0 元数据工具 update_plan，参数 title、steps[{id,title,status,detail?}]（1–12步，稳定唯一 ID，最多一项 running）；不操作磁盘/终端，不取得项目写锁。事件 plan.updated payload={turnId,plan:{id,kind,title,steps,createdAt,turnId}}，每轮固定 plan_<turnId>。既有事件表存储，无迁移。计划文本在注册 schema 中拒绝已知凭据；前端 Zod 校验恢复事件。工具、审批和产物补充可选 turnId 以便分轮；旧事件按用户消息边界回退。

## 安全、失败与边界
计划仅为模型报告的进度，不是执行授权/测试证据；走既有鉴权 Turn、工具预算、审计、取消检查及事务事件。审批仅 approve/reject，参数绑定/TTL/后端授权不变。工具参数只展示现有已脱敏摘要；命令详情补充Manager验证和凭据检查后的规范化CommandParams（无环境），不公开任意工具原始输入。前端异步请求与会话切换隔离。

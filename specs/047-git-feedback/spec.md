# M2-28 Git 空态与刷新提示收敛
用户指出 Git 暂不可用下的重试按钮突兀，刷新时底部出现一行文字。直接授权精简，依赖M2-27 done，必要校验、自行界面验收。
## 目标 / 非目标
Git不可用仅灰色占位，不显示重试文字按钮，原3秒轮询/自动恢复保持。正常Git点击刷新只让现有图标旋转并禁用/aria-busy，不插入“正在处理”整行，避免底部跳动。真实Git动作错误、状态读取失败/旧数据禁写、审批与放弃确认保留。不改API、轮询、权限或实际Git动作。
## 验收
- Given首次读取失败，Then灰色“Git暂不可用”，无重试/写按钮；后续查询可恢复。
- Given有数据，When点击刷新且请求未完成，Then按钮忙/禁用/图标旋转，无额外处理行；完成恢复按钮，数据仍展示。
- Given实际写失败/查询失败/审批，Then原错误和安全状态继续可见。
## 接口 / 安全 / 边界
仅前端反馈样式，无API/DB/配置/依赖或授权变更；不把失败当成功，不隐藏实际错误。
## 测试
组件空态无重试、延迟刷新忙状态先红后绿，既有Git操作/树回归、Web类型、改动Biome/diff。用户只要必要校验，不跑全量构建/E2E。

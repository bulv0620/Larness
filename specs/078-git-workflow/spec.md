# Git 日常操作体验

沿用右侧 Git Tab，缩短查看差异、暂存、提交和推送的操作路径。先交付人工一键推拉，再补树上的目录批量操作。强推、递归放弃、自动合并和任意 Git 命令输入在本切片范围外。

## GX-1 人工一键拉取与推送

- Given 当前分支有上游且状态可用，When 人工点击拉取或推送，Then 当前按钮原位显示进度，不弹审批卡片；完成后局部刷新分支和传入／传出计数。上游在工具栏可见，无上游时禁用推拉并提示原因。
- Given 推拉发生在脏工作区、分支分叉、凭据不可用或项目写锁冲突时，When 执行失败，Then 原面板保持可用，提供可恢复信息。结果不明时提示先核对 Git 状态，网络层不自动发起新操作。
- Given 同一客户端重复提交同一请求标识，When 首次执行仍在途或已结束，Then 返回同一动作，复用标识但更改参数时拒绝。同一快照下的并发写仍受项目锁约束。
- Given CSRF 无效、参数非法、客户端撤销、仓库快照变化或锁失效，When 请求执行，Then 后端拒绝。远端凭据沿用 Server 主机既有配置，响应只返回稳定错误和脱敏信息。

`POST /api/projects/:id/git/remote-actions` 接受 `action`（pull / push）、`expectedSnapshot`（状态接口的摘要）和 UUID `requestId`，返回现有 Git 动作视图。按客户端与请求标识绑定项目、操作和快照，复用持久动作、幂等账本、锁与审计，无迁移。旧 REST 审批流程和 Agent 工具遵从原契约。见 [ADR-066](../../docs/adr/ADR-066-human-git-remote-actions.md)。

## GX-2 目录行暂存和取消暂存

- Given 某分组的目录含可操作变更，When 用户在折叠或展开的目录行点击 `+` / `−`，Then 一次处理该组目录及其子目录内的可操作文件，保留展开状态并更新计数。操作按钮含目标和文件数提示，支持键盘。冲突条目不进入批量清单。
- Given 同一文件有已暂存和未暂存内容，When 取消暂存目录，Then 只改暂存区并保留磁盘内容。目录暂存捕获选中文件当前的工作区版本，包含该目录内选中的删除。重命名按一个状态条目处理源和目标。
- Given 清单含目录、状态不再有效、路径越界或项目锁冲突，When 提交批次，Then 拒绝整个批次并在 UI 刷新状态。一次最多 200 个状态条目，超限时目录按钮提示分子目录或文件操作。

现有 `POST /git/actions` 新增 `stageFiles`、`unstageFiles`，传 `paths`（精确状态路径）和 `expectedSnapshot`。服务端绑定点击快照、复用资源动作与后端鉴权、项目写锁及审计，在锁内复核，按 Git 返回的拼写向 Git 传递 NUL 分隔的字面路径。无数据库迁移、无新增 Agent 工具。目录放弃更改不在本任务范围。

新增 Git 树组件、真实临时仓库和认证浏览器用例，覆盖折叠目录、同前缀目录、中文空格、删除、部分暂存、快照冲突和批量失效。跨平台以 Git 实测为准。

## GX-3 差异树缩进对齐

Given 同一分组含根级文件、展开的压缩目录及子文件，When Git 面板渲染树，Then 同层文件与目录的图标和名称对齐，子项比父目录多一个缩进层级。目录保留展开箭头，文件留出等宽位置。改动只涉及行布局，沿用现有动作和数据契约。认证 Chromium 用行内名称的水平位置验证对齐和缩进。

## 后续工作流

在树操作之后细化组级操作、已打开 Diff 失效与外部变更刷新，再评估获取远端、首次发布、历史和按差异块暂存。同步动作需明确对应远端，拉取失败时停止。

## 验收

使用真实仓库与临时 bare remote 验证授权、重复请求、旧流程、状态冲突、推拉和 UI 反馈；组件测试覆盖禁用和在途状态。跨平台验收分别记录原生 Windows 11、macOS Apple Silicon、Ubuntu 的 Git 版本和结果，覆盖特殊路径、大小写重命名、路径分隔符和凭据失败。每次交付如实列出实测平台和未运行检查。

# M2-12 右侧资源区简化
人类直接要求；依赖 M2-11 done。

## 目标 / 非目标
右侧只包含文件和 Git，移除全部 / 文件 / Git Tab，直接上下展示两分区；保留折叠、拖动、双击均分与键盘调整。Git 不可用 / 非仓库显示简短灰色占位，与文件空态一致，不渲染红色告警长文。文件树移除连接状态 / 刷新整行，监听与自动重连继续工作；真实读取失败仍保留重试入口，真实 Git 写操作失败仍提示。
不修改后端接口、权限、Git 审批、文件保存 / 冲突行为、窗口 Tab 或终端 / 服务浮栏。

## 验收场景
- Given 桌面右栏，When 打开 / 切换项目，Then 无资源视图 Tab，两分区同时存在，折叠与分隔调整可用。
- Given 非 Git 项目 / Git 不可用，When 读取状态失败，Then 灰色简短占位，不显示红色告警或写操作控件。
- Given 默认工作区 / 项目空目录，When 打开，Then 灰色文件空态，无连接状态 / 刷新工具栏；有文件可正常打开，监听到变更自动更新。
- Given Git 写操作或文件读取失败，Then 既有失败 / 冲突反馈与恢复能力保留，不伪报成功。

## 接口与数据 / 安全 / 边界
仅前端展示，REST / WS / DB 无变化；删除本地临时 Tab 选择状态无需迁移。不隐藏后端拒绝，空态不能授权资源写操作；Git 查询失败不展示过期成功结果。监听继续订阅 / 补拉 / 自动重连。窄屏行为不变。

## 测试计划
先更新 Demo Tab 验收并新增真实 Git 不可用灰色占位红测试；文件真实浏览器加无连接 / 刷新行与灰色非仓库断言。实现后 check / build、Demo 与文件 / Git 真实浏览器回归、目视。

# 初始化修复与体验收敛

本补丁位于 G1 后、M2 之前，一次只执行一个 I0 任务。I0-1 修正现有日志契约；I0-2 至 I0-4 依赖 ADR-024 批准，批准前不得实现。

## 目标与非目标

- 日志按实际时间保留；初始化保留既有文件配置，文件/数据库中间状态可恢复且失败关闭。
- 已有加密记录时主密钥丢失或不匹配拒绝启动，保留原数据。
- TUI 默认复用当前有效配置，网络选项进入高级设置；初始化需重启时由 supervisor 在进入仪表盘前应用。
- ADR-025（人类已批准）：取消密码设置与 Argon2id 计算，保留历史哈希；新实例旧列为空标记，无密码登录/恢复入口。本机 IPC / 配对边界保留，不自动改变已有认证来源。
- 保留七个数据子目录和标准数据目录；开发/生产隔离使用显式 LARNESS_DATA_DIR，避免隐式迁移。暂不实现默认开发目录变更。
- 更新通道保留文件/IPC 兼容，向导不再单独询问；更新功能仍属 M5。

## 验收场景（Given-When-Then）

1. Given 同一天多个日志与超过 retentionDays 的轮转日志，When 清理，Then 保留所有未过期日志，只清理过期的本应用普通日志文件，不跟随符号链接或删除其他文件；启动与每日均执行，错误有日志。
2. Given 预置 config.json 与运行环境覆盖，When 初始化，Then 只更新明确向导字段，保留文件中的 trustedProxies/auth/logging/preview/updates；环境覆盖不无意落盘；非法文件拒绝。
3. Given 初始化在文件替换后中断或 DB 提交失败，When 下次启动，Then 按持久化初始化记录恢复配置或原配置；不能提供配置/初始化状态不一致的业务服务。并发初始化仍只有一次成功；审计失败不初始化。
4. Given 数据库已有加密 secret，When master.key 缺失、无效或不匹配，Then 拒绝启动且不生成替代密钥、不删除原记录；恢复正确密钥后可启动；空 secret 库允许生成新密钥。
5. Given 无密码设置，When 本机初始化，Then 不要求密码、历史哈希不变、新实例空标记、旧 IPC 参数被拒绝；Given 首次 TUI 启动与环境自定义 URL，When 使用默认选项，Then 使用有效配置而不是硬编码 URL；默认不询问网络字段及更新通道；高级设置允许修改网络字段并预览 origin/RP ID。
6. Given 初始化改变运行配置，When 保存成功，Then 关闭旧 IPC 后停止旧受管运行环境、启动新环境并重新连接，再进入仪表盘；重启失败退出并保留已保存配置。未改变则不重启。

7. Given 数据目录存在过期日志，When Server 启动，Then 持有实例锁后先等待过期日志清理结束，再创建日志写入器；清理失败可见且不与日志打开并发；每日调度仍运行，关闭后停止。

## 接口与数据

- REST/WS 无新增；config.json 已有键、IPC init.apply 响应保持兼容。ADR-025：IPC protocolVersion=2，init.apply 移除 adminPassword 并将网络字段设为可选补丁；旧密码字段拒绝，历史 admin_hash 保留、新实例写空标记。
- 受管入口只读检查待发布记录来规划启动端口/来源，恢复写入仍由持有实例锁的 Server 完成；记录非法即拒绝。默认设置不把环境覆盖落盘；高级修改与环境覆盖冲突时提示改环境变量。
- I0-2 可在 app_meta 使用初始化恢复记录（Zod 校验，无密码/密钥）；不新增依赖或破坏性迁移。
- I0-3 repository 提供读取加密记录的内部校验入口，不向 Web 暴露密文或密钥。
- 日志 retentionDays 保持现有含义：按文件最后修改时间距当前时间的毫秒数清理。

## 安全与失败边界

仅本机 IPC 初始化；已有认证来源不自动迁移。恢复记录不可含密码/hash/API Key；文件 0600、目录 0700。恢复记录非法或恢复失败时拒绝启动。只处理 Larness 配置与日志，不操作用户源码。

## 测试与验收

每任务先写失败测试；pnpm check、pnpm build；配置/重启改变另跑 pnpm test:e2e:auth 与 pnpm test:e2e:prod，最终跑 pnpm test:e2e。平台声明限于本机验证。

## 开放问题

管理员密码取消方案已通过 ADR-025；本批不新增恢复功能，不更改默认目录。

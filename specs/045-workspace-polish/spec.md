# M2-23—M2-26 工作区体验收敛
2026-11-04 用户明确四项修改并授权五小时额度恢复后自动逐项实施，2026-11-05 续作。依赖 M2-22 done，任务依次实施并独立提交；只做必要校验，全部等待用户统一 UI/安全验收，不通过 G2、不合并、不 push、不修改 README 的验收状态。

## 目标与验收
- M2-23：空会话有柔和多彩图标、引导和快捷建议，点击只填草稿并聚焦，不自动发送/创建资源；移动端自适应、主题一致。
- M2-24：关闭 files/git-diff/browser 窗口关闭所有 Tab，多于一个先确认；脏文件逐个保存/放弃/取消，取消/保存失败保留未处理视图。最小化保留所有 Tab、收到浮栏，动画复用 terminal/services；减少动态效果偏好无动画。终端/服务关闭继续仅隐藏、不终止。关闭文件不删文件、浏览器不停止服务。
- M2-25：新增 autonomous 完全自主策略，选择弹窗明确风险，取消不改策略、确认后生效；后端现有工具 L0–L3 均免逐次人工审批，权限快照和正常授权检查仍执行。只作用于选择此策略后的新 Turn，不替代认证/本机管理通道、资源归属、参数校验、输入租约、锁、幂等、审计、秘密保护。无新增系统管理能力。其他策略不变，非法策略拒绝。详 ADR-040。
- M2-26：文件/Git 同时只展开一个（可全部折叠），flex 动画；Git 顶部提交输入/按钮、已暂存/更改分组目录树、行暂存按钮/打开 Diff、底部推/拉/分支/刷新图标，隐藏常驻说明与表单；分支控件按需弹出，保留真实失败/审批路径，明确只提交已暂存内容、不自动暂存全部。切项目隔离异步结果和输入。

## 非目标
不新增依赖/服务预览能力/部署能力，不取消安全基础检查，不删除用户数据，不自动提交 Git 或运行建议，不改变现有 G2 状态。

## 接口/数据/安全
M2-23/24/26 主要本地视图；M2-25 policy 枚举增加 autonomous，沿用已有 Session/Turn policy snapshot 字段，无 DB 列/迁移。配置与 API 枚举、契约/测试同步。窗口布局仅本地，不以菜单隐藏代授权。风险确认不是沙箱承诺。

## 失败与边界
异步失败必须可恢复；关闭文件遇冲突保留草稿；Git 非仓库灰色占位、写失败明确提示；按钮忙时禁用避免重复。动画卸载/重入/减少动态效果不触发资源操作。

## 测试计划
逐项先针对性失败测试，再最小实现。组件/状态/权限策略与真实策略快照集成按影响覆盖，相关包类型、改动 Biome/diff；不跑全量构建/E2E，用户自行界面统一验收。

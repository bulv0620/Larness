# M2-22 Agent 终端保留 Shell

> **当前验收：2026-11-05 人类统一通过全部修改与 M2 / G2，本切片已完成。** 最终状态/范围/遗留边界见[收尾记录](../030-dev-resources/closure.md)。下文原日期的待验收/实施记录保留为历史证据，不再表示当前阻塞。
用户在了解 Agent 直接把服务当 PTY 主进程后，明确要求解决：Ctrl+C 停服务后回到提示符，关闭 Tab / Agent 显式 stop 才结束整个终端。依赖 M2-21 done；ADR-038 记录该授权。

## 目标 / 非目标
新 Agent dev 终端用受管 Shell 承载批准的前台程序，程序正常/非零退出或 Ctrl+C 后保留同一 PTY，进入账户默认交互 Shell，可继续人工输入和 AI 经租约输入。Tab / ID / cwd 保留，终端 RUNNING 只代表终端存活，不能证明服务运行或 ready。显式 stop / Tab 关闭仍清理整个终端及受管后代，确认后按 M2-21 移除本地视图。
不迁移或重建已有终端，不新增服务状态/健康检测、自动重启/后台化，不扩展项目授权或修改输入审批。不把命令返回码冒充终端退出码。role 复用仍只复用终端，不自动再次执行初始命令；Agent 通过读输出核对并按原输入审批在原终端中重启。

## 验收
- Given Agent 启动真实监听服务，When 人工持租约发送 Ctrl+C，Then 服务端口释放，原终端 RUNNING / ID 不变，后续命令可写项目文件；无 terminal.exit。
- Given 初始命令退出 0/9 或程序不存在，Then 输出保留且可继续输入，不宣称服务启动成功。
- Given 具备引号、空格、换行、控制字符、美元替换的参数，Then 按 argv 字面传递，无脚本插值 / 按键注入；启动仍逐次 L2、执行前重验授权。
- Given 正在运行子进程/返回提示符的终端，When 显式停止，Then 确认清理 Shell 与受管后代；输入租约/人工优先/旧代拒绝不变。

## 接口 / 数据 / 安全
无 REST/WS/DB/config 新字段。shell 字段记录交互 Shell，dev 初始命令继续保存在 launchParams；同参数 role/幂等哈希仍基于批准的程序/参数/cwd。固定 /bin/sh 交互引导脚本使用位置参数，通过子 Shell exec -- 执行外部程序，trap INT 仅保护父 Shell；不忽略子进程 SIGINT。命令结束后 exec 默认 Shell -i，保留 PTY/PID，恢复正常输入。固定脚本不是用户脚本拼接，不经键盘注入、不创建虚假租约，后续输入仍逐次审批。白名单环境/HISTFILE、脱敏、取消未交付清理、未知停止隔离继续生效。账户启动文件与主机 Shell 是可信开发机行为，不是沙箱。

## 失败 / 兼容
引导 Shell 或 PTY 创建失败沿用失败关闭；账户 Shell 选择沿用校验及 /bin/sh 回退。已有 dev 终端保持原进程/自然终态，只有新终端采用新行为；不自动清理用户历史。服务返回值仅在原始输出体现，终端退出码只记录整个 Shell 的退出。临时服务登记未来必须判断实际子进程，不得凭 PTY RUNNING。

## 测试
先红：真实 PTY 人工 Ctrl+C 后端口释放/同 ID 输入、命令 0/9/启动失败后可用、参数原样、显式停止含子进程。相关终端资源 / Agent 工具 / 控制与前端关闭回归，Server/Web 类型、改动文件 Biome/diff；沿用用户必要校验、自行界面验收，不跑全量 check/build/E2E。

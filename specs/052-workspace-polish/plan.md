# M3-11 实施计划

1. 先补回归，确认五项交互的现状与验收差异。
2. 由窗口层识别外部点击，排除窗口内、浮栏和右侧资源区，在视图 store 筛选当前范围内可见且未置顶的窗口，复用现有收起动画和取消机制。最小化仅隐藏当前项目已挂载的窗口 DOM，终端连接生命周期独立于画面。统一终端 Tab 选择并复用原有授权读取与打开逻辑。
3. 在工作区内按终端 Tab 保留 xterm 画面和输出游标。隐藏时只停止连接和输入，重开后按游标补拉。首次历史回放在显示前完成。终态只渲染退出信息，释放 xterm 实例及输出订阅。缩短预览底栏，将成果插入最终答复的页脚之前。
4. 运行检查、构建与浏览器回归。记录验收状态并提交。

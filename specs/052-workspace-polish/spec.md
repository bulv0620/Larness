# M3-11 工作区前端交互优化

2026-11-06 用户直接指定五项优化，在 M4 前交付。依赖 M3-10 完成。

## 目标与范围

精简资源浮窗、终端、预览和会话成果的呈现。沿用现有资源授权、后端生命周期、预览隔离和成果显示时机。M4 按原规格和门禁推进。

## 验收场景

- Given 当前工作区打开多个资源浮窗，When 点击浮窗外的工作区，Then 已置顶的窗口保持显示，未置顶窗口立即开始向浮栏缩小并在动画结束后隐藏。Tab、布局及草稿保留，原点击继续生效。浮窗内、菜单和模态框控件照常交互，浮栏可直接打开或恢复窗口。其他工作区的布局保持原样。
- Given 窗口已置顶或正在收起，When 用户点击黄色最小化按钮或在动画中重新打开窗口，Then 手动最小化仍然可用，重新打开会取消对应动画。开启减少动态效果时直接隐藏未置顶窗口。
- Given 运行中终端已显示输出，When 收起后恢复、切回 Tab 或返回项目，Then 重新核对状态后复用当前页面内的终端画面及回滚区，仅按已有游标补读新增输出。首次打开或刷新没有缓存时，准备好历史画面后再显示。读取失败显示可恢复提示。
- Given 终端有回显，When 后端确认终端进入 EXITED、TERMINATED 或 INTERRUPTED，Then 清空可见回显及辅助输出，只在内容顶部显示终态和已有退出码或原因。打开已结束 Tab 时同样只显示终态。STOPPING 或连接中断继续显示实际状态和回显。
- Given 预览窗口缩至最小宽度，When 显示底栏，Then 只保留简短来源标识，保持单行。
- Given 打开终端窗口，When 上次选中真实 Tab 仍可用，Then 恢复该 Tab；没有有效选择时激活最右侧已有终端 Tab。无本地 Tab 时按当前作用域从后端列表恢复最后创建且仍运行的终端，跳过已结束项，无运行项时显示新建入口，读取失败可重试。
- Given 本轮已有资源成果或产物，When Turn 进入终态，Then 在最终答复正文下、复制和时间栏上显示成果，维持去重。没有最终答复时独立显示已产出成果。

## 接口、数据、安全与边界

复用现有终端列表与详情接口。列表按创建时间和 ID 升序，恢复时按作用域分页并以详情确认 ID、归属及 RUNNING。若候选已结束或被清理，继续尝试较早候选；归属异常或查询失败给出可重试提示。窗口退出后丢弃在途恢复结果。终端屏幕、输出游标和有界摘要仅保存在当前已认证工作区的页面内存中。隐藏时断开当前连接并停止续租，重开沿用既有租约检查。移除 Tab、确认终态或退出工作区时释放画面缓存。终端屏幕清空只发生在前端，输出历史和资源状态仍由后端管理。REST、WS、数据库、持久布局格式和鉴权沿用既有契约。

## 测试计划

组件测试先复现终端选择、空态/分页/重试、成果顺序及预览底栏。浏览器验证外部点击与恢复、真实终端终态和无本地 Tab 时的恢复、窄预览。运行 pnpm check、pnpm build、Demo E2E 与相关认证 E2E。

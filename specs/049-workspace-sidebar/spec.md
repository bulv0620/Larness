# M3-7 工作区侧栏与窗口层修正

用户于 2026-11-05 直接要求调整项目会话状态、折叠和终端／服务浮栏层级。

## 目标与范围

项目会话以已持久化的活跃 Turn 显示旋转指示器，空闲时选中显示蓝点、未选中显示灰点。每个展开的项目默认最多显示五条（含草稿），按最近更新排序，优先保留所选会话及进行中的会话。额外会话通过「展开更多」显示，并可收起。搜索匹配项目或会话标题时可访问折叠内容。资源窗口覆盖与其重叠的终端／服务浮栏。会话归档、历史列表读取上限和资源生命周期沿用已有行为。

五条上限按本次需求设置。项目分组和历史搜索参考 OpenAI 官方文档。 [Projects and chats](https://learn.chatgpt.com/docs/projects)

## 验收

- Given 项目内已有会话，When 未选中的会话开始、运行、结束任务，Then 其指示器随服务端状态在灰点和转圈之间切换；空闲时选择它显示蓝点。
- Given 一个项目有六条以上会话，When 打开侧栏、展开更多、选中较旧会话或搜索其标题，Then 初始最多五条，展开能访问隐藏项，收起保留选中项，搜索能找到折叠内容。
- Given 一个窗口覆盖浮栏位置，When 最大化窗口，Then 重叠位置的点击由窗口接收，关闭后浮栏再次可用。

## 接口与数据

已鉴权的 GET /api/sessions 为列表项增加 hasActiveTurn 布尔字段，沿用现有活跃 Turn 状态定义。现有 system 订阅发送无会话内容的 workspace.sessions.changed 缓存失效通知，订阅或重连后重新读取快照。无需迁移、依赖或新端点。

## 安全、失败与边界

通知在 Turn 落库后发送，收件连接仍需通过鉴权。SQLite 为权威，短暂断线使用重连后的快照恢复。沿用会话列表授权、归档、分页上限及现有窗口视图生命周期。

## 测试计划

先用真实认证 Chromium 回归验证后台会话开始／结束、选中状态及项目内展开和搜索。用 Demo Chromium 验证窗口重叠处命中。运行 check、build、Demo E2E 与相关真实 E2E。

# M2-17 消息框与紧凑审批

> **当前验收：2026-11-05 人类统一通过全部修改与 M2 / G2，本切片已完成。** 最终状态/范围/遗留边界见[收尾记录](../030-dev-resources/closure.md)。下文原日期的待验收/实施记录保留为历史证据，不再表示当前阻塞。
2026-11-04 用户直接要求：回复恢复消息框、批准框更紧凑、不展示批准记录、复制右侧增加时间，只做必要校验、界面自行验收。依赖M2-16 done。

## 目标与非目标
助手正文置于左侧浅色消息框，沿用外围主题、13px正文与现有单列布局；不加头像。复制按钮在框下，右侧显示该条回复本地时间HH:mm，完整日期可查看，取现有createdAt。底部审批缩短默认高度，动作摘要保留可读，完整项目/参数/范围/过期时间折叠到详情。对话内不显示审批记录，后端事件和审计保留。
不修改模型、API、事件/数据库、授权、TTL、批准/拒绝/等待确认/失败重试/多请求流程或资源生命周期。

## 验收
- Given完成回复，Then正文在消息框，复制右侧出现来源于createdAt的time元素；流式期间不显示复制/时间操作行。
- Given审批待处理/已批准/拒绝，Then对话内均无审批记录，待处理请求仍在输入框上方可操作。
- Given审批面板，Then默认只有紧凑标题/动作/详情/操作行，提交中/过期/错误状态和多请求导航不变。
- Given窄屏长文本/命令，Then消息和面板自然换行，详情有界滚动，触屏点击区域沿用44px。

## 安全与边界
隐藏记录仅为呈现，不删除持久事件/审计。时间为已有消息时间而非伪造执行耗时，发送/停止/输入/滚动规则不变。

## 验证
遵照本轮明确要求只做必要校验：时间/隐藏记录组件测试先红后绿，既有对话/审批组件测试、Web类型检查及改动文件Biome检查。不跑全量Server/PTY、全量E2E或构建；视觉由用户自行验收，此指令优先于原全量检查要求。

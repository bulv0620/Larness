# M2-11 纯终端体验
人类在了解当前实现后要求继续优化；依赖 M2-10 done。

## 目标 / 非目标
取消终端内容顶部的常驻运行 / 观察 / 开始输入 / 终止工具栏；交接与接管进入 Tab 操作菜单，关闭仍用 Tab ×。人工 Shell 首次打开且无人持权时自动申请输入权并聚焦；已有人工 / AI 控制时不抢占，主动交出后不自动抢回。Agent dev 终端保持观察，显式申请 / 接管。＋直接打开创建确认，复用现有逐次风险确认与幂等重试。人工 Shell 优先本机账户默认 Shell，不接受浏览器指定程序或环境。
不改变 AI L2 审批、租约协议、终端归属、进程生命周期、目录和环境白名单，不新增依赖。关闭默认 Shell 的启动子进程时，进程归属登记与组终止检查复用最新快照，修复快速 fork 导致误报 STOP_UNCONFIRMED；保留出生身份与整组归属校验。

## 验收场景
- Given 空闲人工 Shell，When 首次打开，Then 无需点开始输入即可输入真实命令；内容没有常驻状态工具栏。
- Given 另一客户端或 AI 持权，When 打开 / 点击内容，Then 不抢占；显式接管 AI 后旧代输入拒绝。
- Given 人工持权，When Tab 菜单交给 AI，Then 后端释放且本视图不自动再申请；点击内容可重新申请。
- Given 多 Tab，When ＋，Then 直接确认创建；取消无请求，同次重试同幂等键；改名和关闭保持原语义与固定高度滚动。
- Given 本机账户 Shell 可执行，When 创建人工终端，Then 使用该程序 -i；不存在 / 不可执行则回退 /bin/sh；不拼接命令字符串、不传递全部管理环境。
- Given 断线 / 续租失败 / 终态，Then 立即禁用输入，保留异常与退出提示，窗口隐藏不终止。

## 接口与数据 / 安全
REST / WS / DB 无变化，后端仍校验 riskAcknowledged=true、认证 / CSRF / 真实连接租约。默认 Shell 从 OS 账户信息读取（不是来自 Web / 模型），仅绝对可执行文件，否则 /bin/sh；白名单环境与 HISTFILE=/dev/null 保持。所有输入继续走既有序号、代际与审批。

## 失败 / 测试
自动申请竞态由后端裁决，失败不循环抢权，用户可在菜单或点击重试。先写 UI / Shell 选择红测试；真实 PTY 双客户端、续租 / 接管、默认工作区、Tab E2E；check / build / Demo 回归与目视。

评估日期 2026-11-15。实现进度见[任务](tasks.md)，验收场景见[规格](spec.md#6-验收场景)。

| 路线 | 已验证 | 真实账号待验收 |
|---|---|---|

Models.dev 的公共地址本轮复查返回 HTTP 200。OpenCode Go 的公开目录可直接读取，本轮未用套餐 Key 发起推理。缺乏目录授权或能力字段时，可在对应连接登记模型和补充能力。公开目录的响应与请求夹具的通过均独立于真实账号验收。

截图专项通过受认证的 API 验证会话归属、纯文本模型拒绝、仅图片的 Turn、工具续步及事件仅含附件 ID。兼容协议的请求测试验证图片序列化。Chromium 在开发和生产构建中验证添加 Key 后的目录同步、窄屏截图草稿、切换模型、提交及刷新回放。

截图支持 PNG 和 JPEG，每轮最多四张，每张最多 4 MiB。历史消息在界面回放截图，后续新 Turn 的模型上下文使用文字标记；当前 Turn 的工具续步仍携带图片。

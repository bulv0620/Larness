# 项目资源文件管理器

2026-11-14 用户确认首版方案及预览 Tab 语义，授权按顺序实施。

## 目标与范围

在右侧文件栏和现有 Monaco 窗口完成浏览、查找、编辑与单项文件整理。首版包含 FR-1 浏览联动、FR-2 快速打开、FR-3 新建与整理。批量、拖拽、删除、上传下载、全项目内容搜索及编辑布局调整在本切片范围外。

## FR-1 文件树与窗口联动

- 同一文件窗口最多一个预览 Tab。树行单击预览，双击或 Enter 正式打开，开始编辑也转成正式 Tab。再次打开已存在的文件始终聚焦，聊天成果和 Git 的显式打开会固定预览。Git 查看差异仍使用 Diff 窗口，Diff 可显式打开工作区文件。
- 树行方向键可上下移动、左右展开或回到父级。单独记录每个授权范围的展开状态。可折叠所有子目录、复制选中项的项目相对路径。
- 文件窗口「在文件树中定位」打开当前项目的文件栏并展开祖先，逐页加载到目标，选中、高亮和滚动。文件隐藏、消失或目录读取失败时提示；切换工作区不沿用待定位请求。布局仍使用桌面文件栏。
- 先授权读取再打开。读取失败保留已有 Tab。快速点击以最新请求为准，切换工作区后旧请求不得抢焦点。草稿及保存中的文件不能被预览替换。
- 使用既有 GET、文件监听和现有路径权限。新视图偏好仅保存在浏览器，不持久化文件正文或草稿。无 REST、事件、数据库、配置或 Agent 工具契约改动。

### 验收场景

| Given | When | Then |
|---|---|---|
| 当前窗口有一个预览 | 单击另一个文件，再双击打开或开始输入 | 只替换预览，固定后的 Tab 和草稿保留 |
| 同一范围已用聊天成果或 Git 打开文件 | 从树打开同文件 | 聚焦原 Tab |
| 预览请求 A 慢于随后请求 B，或 A 读失败 | 请求返回 | A 不抢焦点，失败保留已有 Tab |
| 文件在已折叠目录或目录后续分页 | 从编辑器定位 | 展开、选中并滚动到目标 |
| 文件不在树的可见范围 | 从编辑器定位 | 提示找不到，继续保留文件窗口 |
| 两个授权范围各自展开不同目录 | 切换范围或刷新 | 各自恢复展开状态，导航限制在当前范围 |

## FR-2 文件名与路径快速打开

在「文件」栏提供可点击入口。输入文件名或项目内相对路径，匹配大小写无关的子串和顺序字符，名称精确或连续匹配优先。结果显示文件名和父目录，方向键选择、Enter 打开普通 Tab、Escape 关闭。空输入不请求扫描。新查询和工作区切换清除旧结果，读取失败保留对话框并显示错误。

接口、限制、安全与错误见 [REST 文件搜索](../../docs/contracts/rest-api.md#fr-2-文件快速打开)。现有文件读取继续决定结果能否打开，已经打开的文件去重聚焦。无新表、配置和 Agent 工具。

| Given | When | Then |
|---|---|---|
| 同名文件分布在未展开目录 | 输入文件名或路径片段 | 显示匹配及父目录，方向键与 Enter 打开选中结果 |
| 搜索访问受保护目录或符号链接 | 在项目中查找 | 结果与树的路径和忽略边界一致 |
| 旧查询返回时输入或工作区已变化 | 接收响应 | 只展示当前查询和范围的结果 |
| 扫描达到预算或结果超过上限 | 有部分结果 | 明确标注结果受限，支持缩小关键词 |

## FR-3 新建、重命名与移动

文件栏可新建空文本文件或目录，默认使用选中目录，选中文件时使用其父目录，无选中时使用根目录。新建和重命名使用树内输入。文件行右键菜单可重命名，或在同范围的目录选择器中移动。新文件打开为普通 Tab。成功后定位目标，发起浏览器的已打开 Tab 及内存草稿迁移到新路径，保留原保存基准。其他浏览器刷新目录和文件快照，旧路径草稿保留在原 Tab。

操作仅面向已认证用户。文件移动及改名限单个常规文件和同一工作区，要求来源版本。覆盖、目录改名或移动、跨卷复制和批量均在范围外。见 [REST 契约](../../docs/contracts/rest-api.md#fr-3-单项文件操作)。

| Given | When | Then |
|---|---|---|
| 选中目录 | 新建文件或子目录 | 写入实际磁盘并选中新项，空文件可立即编辑 |
| 已打开文件有草稿 | 改名或移动 | 磁盘路径变化，原 Tab 和草稿随目标路径迁移 |
| 目标已存在，或来源内容已变 | 提交移动 | 报同名或版本冲突，保留原文件和草稿 |
| 进程退出或结果提交失败 | 重启后 | 确认无副作用则结束操作，能核实移动完成则补记，结果不明保留写入屏障 |

## FR-4 文件行右键菜单

文件行只展示名称和图标。右键在指针处打开重命名和移动菜单，键盘可通过 Shift+F10 或菜单键打开。普通单击和双击仍按原规则打开文件，菜单操作复用 FR-3 的权限和路径校验，接口与数据保持原契约。验收覆盖无三个点、右键重命名、右键移动及键盘退出。

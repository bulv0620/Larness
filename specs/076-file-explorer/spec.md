# 项目资源文件管理器

2026-11-14 用户确认首版方案及预览 Tab 语义，授权按顺序实施。

## 目标与范围

在右侧文件栏和现有 Monaco 窗口完成浏览、查找、编辑与单项文件整理。首版包含 FR-1 浏览联动、FR-2 快速打开、FR-3 新建与整理。批量、拖拽、删除、上传下载、全项目内容搜索及编辑布局调整在本切片范围外。

## FR-1 文件树与窗口联动

- 同一文件窗口最多一个预览 Tab。树行单击预览，双击或 Enter 正式打开，开始编辑也转成正式 Tab。再次打开已存在的文件始终聚焦，聊天成果和 Git 的显式打开会固定预览。Git 查看差异仍使用 Diff 窗口，Diff 可显式打开工作区文件。
- 树行方向键可上下移动、左右展开或回到父级。单独记录每个授权范围的展开状态。可折叠所有子目录、复制选中项的项目相对路径。
- 文件窗口「在文件树中定位」打开当前项目的文件栏并展开祖先，逐页加载到目标，选中、高亮和滚动。文件隐藏、消失或目录读取失败时提示；切换工作区不沿用待定位请求。布局仍使用桌面文件栏。
- 先授权读取再打开。读取失败保留已有 Tab。快速点击以最新请求为准，切换工作区后旧请求不得抢焦点。草稿及保存中的文件不能被预览替换。
- 使用既有 GET、文件监听和现有路径权限。新视图偏好仅保存在浏览器，不持久化文件正文或草稿。无 REST、事件、数据库、配置或 Agent 工具契约改动。

### 验收场景

| Given | When | Then |
|---|---|---|
| 当前窗口有一个预览 | 单击另一个文件，再双击打开或开始输入 | 只替换预览，固定后的 Tab 和草稿保留 |
| 同一范围已用聊天成果或 Git 打开文件 | 从树打开同文件 | 聚焦原 Tab |
| 预览请求 A 慢于随后请求 B，或 A 读失败 | 请求返回 | A 不抢焦点，失败保留已有 Tab |
| 文件在已折叠目录或目录后续分页 | 从编辑器定位 | 展开、选中并滚动到目标 |
| 文件不在树的可见范围 | 从编辑器定位 | 提示找不到，继续保留文件窗口 |
| 两个授权范围各自展开不同目录 | 切换范围或刷新 | 各自恢复展开状态，导航限制在当前范围 |

## 后续任务范围

- FR-2 在当前授权范围内按文件名和相对路径模糊匹配，覆盖未展开目录并复用忽略规则。搜索结果显示父目录。后端搜索限额、响应及回归在该任务实现前落入契约。
- FR-3 对单项创建空文件 / 目录、重命名及移动提供树内入口。服务端复用路径防护、根锁、幂等、审计与资源事件；同名和来源变化返回冲突，保留草稿。写入协议、恢复及跨客户端通知在该任务实现前落入契约。

# 项目资源文件管理器实施计划

1. FR-1 复用 windowStore 的真实路径去重与作用域分组、既有编辑器及目录分页。预览标记随 Tab 保存，首次编辑时固定。视图状态从导航 store 读写，定位复用当前文件树请求与 Query 分页。
2. FR-2 使用逐目录流式扫描（复用路径、防链接和忽略规则），对匹配项排序并封顶。Web 使用 Query 按 scope 和输入缓存，搜索框防抖，复用 openFile 的授权与去重。
3. FR-3 在文件服务层落实结构变更与恢复协议，再接新建、改名、移动及 Tab 路径衔接。

4. FR-4 用现有菜单组件接文件行右键与键盘触发。

逐项先写测试、运行验收与整仓门禁，并提交后再开始后续任务。

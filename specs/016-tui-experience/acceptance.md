## T0-1（2026-11-02，macOS / Node 20.19.3）

- 人类完成 spec 后指令“开始实现”，G-Spec-TUI / ADR-027 通过；本项建立终端生命周期、输入所有权、初始化适配、概览与退出确认。
- 测试先行：新增终端测试首先因缺少实现失败；新增概览退出/读响应失效测试。已有配对/设备/日志通过受控页面适配仍可操作，完整页面分别属于 T0-2/T0-3。
- 表单适配两轮发现测试输入早于 Inquirer 首帧、Inquirer 结束测试输出流的问题；按 AGENTS §9 暂停说明，人类明确批准继续后增加独立输出代理，连续表单/取消/菜单输入均通过，无未处理异常。
- 快速方向键与回车在同一输入包时需保留顺序：增加有界键盘队列；业务等待和表单切换丢弃过期按键，避免重复操作。
- 新增真实 PTY 场景暴露首帧打印前后信号处理窗口，修复为先注册信号再进入独立屏幕；启动中 SIGTERM 也恢复终端。
- `pnpm check`：agent 32 / server 276 / web 26 通过；`pnpm build` 通过，现有 Web chunk 提示不阻断构建。
- `pnpm test:tui:pty`：非 TTY 启动前拒绝；正常初始化、默认取消/确认退出；100×30 → 60×16 → 80×24；Ctrl+C、SIGTERM、启动中 SIGTERM、启动失败，全部通过。检查原终端 ECHO/ICANON/ISIG、替代屏幕、监听端口、实例锁和 IPC 均恢复/释放。
- `pnpm test:smoke:init`：真实构建产物的初始化改端口/重连与中断配置恢复通过。
- ADR-027 两个纯 JS 工具只新增当前锁定版本的直接声明，lockfile 仅增加 6 行 importer；无新增原生包或版本升级。server 四入口总计 290.80 kB，tui.js 34.69 kB（gzip 11.31 kB）；记录是当前构建结果，不作为性能/支持平台外推。
- 测试使用临时目录、空闲端口和假数据；未删除/迁移用户数据。Linux/Windows 本轮未验证。
- 尚未完成：T0-2 配对/设备页面，T0-3 日志/审计阅读与整体人工视觉验收。本项通过不等于整个 TUI 切片已完成。

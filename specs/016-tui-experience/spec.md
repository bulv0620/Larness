# TUI 页面与交互统一

> G-Spec-TUI 于 2026-11-02 随人类“开始实现”指令确认；按 T0-1 → T0-2 → T0-3 先于 M2 实施。
> 配套：[页面契约](../../docs/contracts/tui.md)、[渲染与输入 ADR](../../docs/adr/ADR-027-tui-screen-and-input.md)、[评审清单](review.md)。
> 页面化已实施；自动化与脱敏画面见 acceptance.md，2026-11-02 人类明确“验收通过”。
> 约束：[ADR-023](../../docs/adr/ADR-023-tui-as-managed-entry.md)、[IPC 契约](../../docs/contracts/ipc.md)、[安全模型](../../docs/architecture/security.md)。

## 1. 背景与问题

当前 TUI 以追加输出和命令输入组成循环。查看日志后立即打印控制面板；返回面板后旧日志、配对码、设备操作结果仍混在终端回滚内容中。配对码已增加回车停留，但其他页面缺少统一的停留、返回和错误处理规则。

## 2. 目标

- G-1：同一时刻只显示一个完整页面，切换/刷新在独立屏幕区域重绘，当前页面不混入上一页内容。
- G-2：控制面板精简为概览与功能入口；配对、设备、日志、审计各有独立页面。
- G-3：统一选择、确认、返回与退出；内容页持续停留，操作结果和错误可读，不自动跳回概览。
- G-4：正常退出、信号、启动失败与重连失败均正确恢复终端显示和输入状态，并保持受管服务生命周期。

## 3. 非目标

- 不改变 IPC/REST/WS、数据库、配置、认证来源、配对码有效期或消费规则。
- 不增加后台运行方式，不把业务状态/权限判断迁入 TUI。
- 首版不做日志自动跟随、自动刷新、搜索筛选、导出或无限历史加载。
- 不新增主题系统、鼠标操作、面板拖动或业务功能；依赖方案见 ADR-027（accepted），不引入 React / Ink 或新原生库。
- 不清空终端全局历史或声称擦除此前会话的回滚内容；目标是管理本次 TUI 的独立屏幕。

## 4. 页面与导航

采用独立终端屏幕，固定页头、正文和底部按键提示。初始化页仅展示操作说明与当前 Web 地址，不展示已移除密码功能的说明（2026-11-02 人类直接指定文案修正）。启动检查、初始化向导与日常页面共用终端生命周期；退出后恢复进入 TUI 前的终端画面，必要的退出摘要在恢复后输出。

| 页面 | 内容 | 停留与返回 |
|---|---|---|
| 控制面板 | 运行状态、Web 地址、待配对数、在线会话数、告警；配对/设备/日志/审计/退出入口 | 选择入口后进入对应页面；不默认展开审计和日志 |
| 配对申请 | 短编号、时间、来源、客户端信息、可用批准方式 | 选择申请进入操作；取消操作回到申请列表，Esc 返回控制面板 |
| 配对码 | 突出显示一次性码、到期时间、对应申请及批准方式 | 等待回车返回控制面板；Esc 返回申请列表；不得自动被面板或刷新覆盖 |
| 设备列表/详情 | 当前设备状态、Passkey 备份标志、时间信息；详情中提供撤销 | Esc 返回上一级；撤销二次确认，结果在详情页停留，手动返回 |
| 日志 | Server 文件日志和 supervisor 捕获的子进程输出，来源明确分区 | 独立阅读页，上下滚动、手动刷新；Esc 返回控制面板 |
| 审计 | 最近审计列表，保留时间、动作、结果与必要关联信息 | 独立阅读页，上下滚动、手动刷新；Esc 返回控制面板 |
| 退出确认 | 明确提示“退出并停止 Server 与 Web” | 默认取消；确认后停止全部；取消回到控制面板 |

### 按键约定

- 列表用 ↑/↓ 选择，Enter 打开/确认；阅读页 ↑/↓ 滚动，PageUp/PageDown 翻页，Home/End 到当前快照起止位置。
- Esc 返回上一级；已处于控制面板时保持原页。确认框的 Esc 等同取消。
- `r` 在支持刷新的列表/阅读页重新获取快照；输入框中所有普通字符按文本处理。
- `q` 仅在控制面板打开“退出并停止服务”确认；取消后继续运行。移除重复的“关闭 server”菜单项，IPC server.shutdown 能力保持。
- Ctrl+C 保持全局停止全部服务的现有行为，不改成返回页面；退出前尽力恢复终端。SIGTERM/SIGHUP 同样清理；SIGKILL/终端崩溃仍有 ADR-023 的残余限制。
- 底部只显示当前页面可用的按键，不要求先输入命令字母再按 Enter。

## 5. 阅读、刷新与反馈

- 进入日志/审计页时读取一次快照；用户手动刷新前，内容与滚动位置不被后台输出改变。Server 日志请求 logs.tail({lines:200})（最多 200 行），子进程输出截取现有缓存最后 300 行；audit.tail({limit:200})（最多 200 条）。首版不扩展 IPC。
- 刷新成功更新当前页面：日志原来在底部则仍停在新底部，否则保持可见正文的行偏移并限制在新范围；审计原来在顶部则仍在最新记录，否则保持偏移并限制在新范围；不跳回控制面板。选择列表按资源 ID 保持选中项，原项消失则选最近有效项；空列表不保留失效选择。等待请求时禁止重复发出同一操作。
- 日志与长文本按正文宽度换行，正文超高可滚动；页头/底部提示始终可见，不把整份内容追加到终端。
- 配对操作中遇到长来源地址时保持所选操作可见，PageUp/Down、Home/End 可阅读上下文；↑/↓ 继续选择操作。
- 无待配对、无设备、无日志、无审计时显示明确空态，停留原页并允许刷新/返回。
- 操作成功在当前页展示结果；操作失败保留当前上下文和可读错误，提供返回/刷新，写操作重新执行必须由用户明确触发并重新确认。
- 离开配对码页后不再把明文码带入其他页面、通知、历史结果或调试输出；重新进入申请列表不重新获取旧码。过期仍显示到期信息，返回/刷新查询状态，不自动延长或重新生成配对码。

### 具体阅读与操作规则

- 日志使用“Server 文件 / 子进程输出”两个来源视图，←/→ 切换；切换不重新请求，分别保留滚动位置；子进程行保留来源前缀。审计首版只显示现有结构化摘要，不新增详情查询。
- 第一次进入日志页定位当前来源末尾，审计页定位最新记录；切到其他页面后再次进入重新获取快照，不保留过期内容。每页显示快照获取时间、来源与行数/条数；时间使用本机时区并明确时区。
- 单来源读取失败时显示该来源的错误，另一来源仍可查看；刷新失败保留上次成功快照并标记“刷新失败，当前为上次快照”。没有成功快照时显示错误态，不显示“无日志”冒充空态。
- 日志和审计原始数据仅保存在本次页面快照，不写第二份磁盘文件，不输出到终端回滚历史；离页释放快照。
- 所有确认默认选“取消”；列表不通过可变行号执行操作，而以加载时对应的资源 ID 提交。撤销后的详情明确标记已撤销，不提供重复撤销动作。
- 配对码页不提供 r 刷新或重新生成。页面停留不延长 expiresAt；离页即清空本机明文码引用。按 r 刷新配对列表不能重取旧码，重新配对必须由浏览器发起新申请。
- 请求使用现有 IPC 5 秒超时，重连最多 2 次；只读请求允许 Esc 返回，晚到结果不得覆盖新页面；写请求发送后不可用 Esc 假装取消，等待结果或超时期间仅允许全局停止。
- 写请求超时或断线时显示“结果待确认”，不宣称失败即未执行，不自动重试；恢复连接后由用户刷新列表确认。若批准可能成功但未收到一次性码，明确告知无法重取，返回配对列表并由浏览器重新申请。
- 非连接类 IPC 错误留在当前页；连接断开时暂停写操作并展示重连状态。恢复后使已打开的确认框失效，重新加载实际状态并由用户重新确认；重连耗尽按原受管生命周期清理退出。
- 界面展示服务返回的稳定错误码及本地可恢复提示，不直接打印任意异常原文。Ctrl+C 全局停止、SIGTERM/SIGHUP 处理和停止超时沿用 ADR-023；界面清理失败不伪装为退出成功。

## 6. 验收场景

| ID | Given | When | Then |
|---|---|---|---|
| A1 | 已进入概览 | 多次打开日志并返回，再刷新概览 | 当前屏幕始终只含当前页面；旧日志、配对码和重复面板不堆叠 |
| A2 | 已批准 allow_once 或 trust | 展示配对码并等待，然后按 Enter | 等待期间不出现概览；回车后概览不残留明文码；Esc 则返回申请列表 |
| A3 | 日志超过一屏 | 滚动阅读，期间子进程继续输出，再手动刷新 | 阅读位置不被输出打断；刷新仅更新日志页；正文可完整浏览，底部提示可见 |
| A4 | 概览、设备和审计有数据 | 使用选择、Enter、Esc、r 以及空态返回 | 导航层级和提示一致；设备结果停留当前页；审计不混入概览 |
| A5 | 控制面板且服务运行中 | 打开退出确认，先取消再确认 | 取消不停止服务；确认只关闭一次全部受管进程，恢复原终端画面/光标/输入模式 |
| A6 | 输入框或配对/设备子页 | 输入普通 q 字符或执行 Esc | 输入框不触发全局退出；Esc 取消当前步骤，不隐式批准/撤销/关闭服务 |
| A7 | IPC 请求失败或返回校验不通过 | 加载/刷新/提交操作 | 当前页显示失败，不伪造成功；可返回/刷新；不因刷新自动重放写操作 |
| A8 | 审批/撤销被拒绝、过期或已被处理 | 确认写操作并收到失败 | 保留可读错误和上下文，返回列表查询实际状态；不默认放行或重复生成码 |
| A9 | 退出确认/阅读/输入中的任意页面 | Ctrl+C、SIGTERM 或 SIGHUP | 仍停止全部受管服务，释放 IPC/锁，尽力恢复终端；清理幂等 |
| A10 | 已进入独立屏幕 | 启动失败或 IPC 重连耗尽 | 恢复终端后输出脱敏诊断并清理子进程，不留下隐藏光标或原始输入模式 |
| A11 | 终端缩窄/变矮，或不支持交互 | 调整到小于支持尺寸，或以非 TTY 启动 | 小尺寸提示调整并保留返回/退出能力；非 TTY 明确失败，不提供隐式 headless；不错误清理其他终端历史 |
| A12 | 日志/客户端标签带 ANSI 控制序列，测试数据含假密钥与假码 | 阅读、切换和退出 | 外部文本不能注入控制序列破坏页面；秘密不进入日志/审计/快照；一次性码仅在本机码页面出现 |
| A13 | 批准/拒绝/撤销已发送但 IPC 超时或断开 | 等待结果并尝试 Esc、r 或再次确认 | 不重放写操作，不以返回表示撤销；超时显示结果待确认，用户可刷新查实际状态；丢失的配对码不重新读取 |
| A14 | 只读页面请求尚未完成 | Esc 返回后旧结果到达，或重连后恢复 | 旧响应不覆盖新页面，旧确认不沿用，重新加载并确认后才能写入 |
| A15 | 首次运行进入初始化向导 | 输入文本 q/Esc、确认保存或取消 | 输入/向导只有一个 stdin 所有者；取消不提交初始化，已提交结果不重复；需要重启时终端不退出到 shell，不显示重复面板 |
| A16 | 最近日志有两个来源，一侧刷新失败 | 切换来源、阅读和再次刷新 | 成功来源可读，失败来源标明失败；已有快照明确标记旧数据，不能以空态替代错误；来源滚动各自保留 |

## 7. 接口、数据与安全

- 沿用当前 IPC protocolVersion=1 与 system.status、pairing.*、devices.*、logs.tail、audit.tail；无新增方法、字段、配置键或数据库迁移。
- TUI 仍通过已鉴权的本机 IPC 获取状态，不直接读写数据库；本机 Token、权限及审批校验保持。
- 页面/选择/滚动是本机视图状态，不替代后端权威状态；切页不终止 Agent、终端或业务服务，退出仍按 ADR-023 停止受管进程。
- 禁止将配对码、Token、Cookie、API Key 写入日志、审计或测试截图；伪造测试码只用于自动化。外部展示文本中的终端控制序列需过滤，不干扰布局和输入。
- TUI 页面契约及 ADR-027 已获人类批准后实施；不修改现行 IPC 方法或已冻结 ADR 原文。

## 8. 失败、边界与恢复

- 页面加载保留页头与底部提示；有限等待超时后显示错误，不无限卡在加载状态。
- 输入时不自动重绘抢焦点；首版不做周期刷新或业务事件弹页。
- 最小完整布局为 80×24；更小尺寸显示空间不足提示，暂停业务输入及重绘内容，只接受 Esc 返回和 Ctrl+C 全局停止，恢复尺寸后保留原页/选择/滚动位置。小尺寸不自动批准、撤销或退出。
- Unicode/中文宽度、长地址、多行日志、终端 resize 必须覆盖；不显示超出当前屏幕的菜单或失去返回入口。
- 正常退出与可处理异常恢复终端；不承诺 SIGKILL 下恢复。清理错误不得被伪装为成功。

## 9. 测试与验收计划

- 单元：页面状态/导航、选择与滚动边界、按键上下文、空态/失败态、外部文本控制字符过滤。
- 集成：延迟 IPC/失败 IPC/重复按键；两种配对码停留与退出、设备确认及结果；日志/审计手动刷新与阅读位置。
- 真实 PTY：启动、初始化、切页、resize、退出取消/确认、Ctrl+C/信号、启动失败和重连失败后的终端恢复；断言子进程、锁与 IPC 释放。
- 人工视觉：100×30 和 80×24 中文终端各一组无真实秘密的界面记录；依次进入日志、返回、查看配对码、回车，确认无页面堆叠；60×16 验证空间不足提示。
- 实施任务需先写失败测试，再运行 pnpm check / pnpm build 与针对性 PTY 验收；浏览器链路仅在配对行为或接口变动时扩大回归。
- 实施验收记录见 acceptance.md；自动化结果与人类验收结论分开记录。

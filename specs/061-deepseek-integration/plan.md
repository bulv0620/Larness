# DeepSeek 官方接入实施计划

方案处于评审阶段。需求与验收见 [spec](spec.md)。

1. **官方目录与模型能力**。沿用模型服务和 Secret Store。固定官方域名并校验目录响应，为选择器、Turn 和上下文构造提供一致的窗口与档位。
2. **思考设置与工具续跑**。沿用现有 DeepSeek SDK，发送时固定档位。验证开关、三档、多次工具调用、后续轮次和模式切换，再决定跨重启恢复方案。
3. **上下文圆环**。运行时分别记录单次输入和整轮累计。前端以同次请求快照计算占比，按既有事件恢复机制处理刷新与重连。

各任务先写可复现的回归测试，再更新对应契约。执行 `pnpm check`、构建和相关认证浏览器回归。用授权测试凭据记录官方端点的能力与工具续跑结果。

# M2-9 项目窗口与终端交互修正

> **当前验收：2026-11-05 人类统一通过全部修改与 M2 / G2，本切片已完成。** 最终状态/范围/遗留边界见[收尾记录](../030-dev-resources/closure.md)。下文原日期的待验收/实施记录保留为历史证据，不再表示当前阻塞。

用户于 2026-11-04 明确要求本次产品行为，按该指令实施，G2 仍待验收。

## 目标 / 非目标
取消 header 资源入口；右栏仅文件 / Git。聊天框上方浮栏提供项目终端、服务入口及最小化 / 关闭保留的窗口。每项目独立窗口，无项目筛选器。关闭窗口保留全部 Tab；终端 Tab 关闭仍终止受管进程。终端支持创建、持久改名、输入、显式人机交接，默认项目 cwd。隐藏原生 Tab 滚动条，保留横向滚动和键盘访问。服务后端与隔离预览仍属 M3，真实模式不得呈现 Mock 状态。

## 验收场景
- Given A/B 项目有窗口，When 切项目，Then 只显示当前项目窗口 / 浮栏，返回恢复原 Tab / 布局，不启停资源。
- Given 文件 / Diff / 终端窗口，When 关闭或最小化，Then Tab 和草稿保留，浮栏可恢复。
- Given 多个 Tab，When 横滚或键盘切换，Then 行高固定，当前 Tab 可见，滚动条不占高度。
- Given 项目终端，When 新建 / 改名 / 刷新，Then 真实 PTY 在项目 cwd、名称持久化，不重建进程。
- Given 运行终端，When 关闭 Tab，Then 等待真实终止，失败保留 Tab；窗口关闭无终止。
- Given 手动 Shell 或 AI 开发终端，When 当前项目 AI 获取空闲输入权，Then 可输入 / 中断 / 读取 / 释放；其他项目拒绝，人工持权时 AI 不抢占；人工可接管 AI。

## 接口与数据
新增 terminals.title 可空列（0009 非破坏迁移）；POST /api/terminals/:id/rename { title } 返回 Terminal DTO。title 1–80 字符且拒绝控制字符与已知秘密；审计仅记录动作不记录名称。Terminal DTO 增加 nullable title。Agent 控制 / 读取扩展至同项目手动 Shell，停止工具仍只停止 Agent dev。项目终端发现由 Turn 上下文提供有界 ID / 标题列表，不暴露主机路径或输入正文。

## 刷新恢复补充（2026-11-04 人类授权）
导航持久化草稿身份与 projectId，不保存输入正文。服务器快照加载成功前不纠正导航；有效草稿 / 项目优先保留，失效资源仅回退当前项目，不自动跳其他项目。无项目选择在真实模式进入本地草稿（后续共享默认工作区另任务实现）。

## 安全 / 边界
沿用鉴权、CSRF、项目归属、L2 输入审批、租约 generation / sequence、秘密保护。不自动抢人工输入，不宣称沙箱。终端创建保留简短一次确认。名称不得影响 dev role 去重。布局迁移仅拆分视图，不调用后端。

## 测试计划
先失败的项目窗口 / 关闭保留 / 布局迁移测试；真实 PTY 手动终端 Agent 控制、跨项目拒绝、改名持久化与输入验证；组件 / Playwright 验证浮栏、Tab 溢出、创建 / 改名 / 关闭。pnpm check、build、相关真实浏览器及 Demo 回归。

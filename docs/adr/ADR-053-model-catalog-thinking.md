# ADR-053 DeepSeek 官方模型目录与思考档位

- 状态 accepted（2026-11-07，用户直接指定方向：旧模型档案全部忽略，做完整的 DeepSeek 接入，支持选择模型与思考程度，界面仿 Codex 效果）。
- 关联 [ADR-021](ADR-021-passkey-v1.md)（无关）之外的：[M1 模型 Profile](../../specs/020-workspace-agent/spec.md)、[M5-1 spec](../../specs/061-deepseek-integration/spec.md)、[工程宪法](../../CONSTITUTION.md) 第六 / 第十条。
- 实施状态：规格 `ready`，按 M5-1a → M5-1b / M5-1c 落地；未实施前不得宣称已支持官方目录或思考档位。

## 背景

Larness 目前只内置 `deepseek-chat`，窗口硬编码 128,000，模型选择依赖用户手动创建 Profile。上下文圆环用整轮累计输入 tokens 除以该窗口，多工具轮次会提前满格。官方已提供模型目录接口与思考档位，服务端也已升级到支持 `thinking` / `reasoningEffort` 的 SDK。

用户明确要求：不迁移旧模型档案（忽略即可，不删除），改为由官方目录驱动的完整接入，模型与思考程度都在输入框选择，交互参考 Codex。

## 决策

1. **旧档案忽略**：`model_profiles` 既有行保留，不再出现在选择器、项目默认值与新 Turn 解析中；历史 Session / Turn 引用照常展示。不做删除或改写，避免破坏历史与用户数据。
2. **目录驱动**：服务端从固定官方端点同步模型列表，按凭据隔离缓存，Zod 校验后只保存展示字段（模型 id、显示名、窗口、档位、默认标记）。模型选择不再要求用户预建 Profile。
3. **模型与档位随 Turn 固定**：Session 保存最近选择；Turn 创建时快照 `provider / model / thinking / context_window / 凭据引用`。运行中改选只影响下一 Turn。
4. **思考默认开启**：默认发送 `thinking.type=enabled` 且不带 `reasoningEffort`（官方默认）；可选 `low` / `high` / `max`，保留 `disabled` 作为对照与排障选项。
5. **推理数据先实测**：M5-1a 不持久化推理数据；M5-1b 用授权凭据实测同轮 / 跨轮 / 重启要求后再定保留范围。推理正文禁止进入 REST、WS、可见对话、日志、审计与跨模型上下文。
6. **圆环改单次口径**：每次模型请求写一条 `model.usage` 事件，圆环用「最近一次单次输入 ÷ 同次窗口」；整轮累计仍保留在 `turn.completed.usage`。无匹配统计显示「暂无统计」。
7. **界面**：Composer 模型控件显示「模型名 · 档位」，点击打开两段式浮层（模型 / 档位）；设置页保留凭据管理并增加目录与默认模型，旧 Profile 列表移除。沿用现有 UI 组件与 token。

## 备选方案

- **保留 Profile 体系并叠加目录**：需要用户为每个模型建 Profile，与「直接选择模型」冲突，且旧窗口 / 能力字段会继续误导圆环。
- **自动迁移所有旧 Profile 到 flash**：静默改写用户配置，历史记录与选择语义混乱，且用户已明确「忽略」。
- **思考默认关闭**：与用户「默认开启」的指示相反；当前 harness 也不使用非思考模式。
- **立即持久化推理数据**：在未验证官方跨轮 / 重启要求前引入新的敏感存储面，违反最小化原则。

## 影响

- 产品 / UI：输入框与设置页模型区改版；旧 Profile 不再展示；模型与档位即时可见。
- API / 契约：新增目录读取 / 刷新接口、`model.usage` 事件、Turn 创建接受 `model` / `thinking`；旧 `modelProfileId` 参数保留兼容。详见 [REST](../contracts/rest-api.md)、[WS 事件](../contracts/ws-events.md)、[数据模型](../contracts/data-model.md)。
- 数据 / 迁移：`0015_model_catalog` 新表与可空列；不删除、不回填旧行；升级保留事件序号。
- 安全 / 权限：目录接口需认证，刷新校验 CSRF；上游地址固定；推理数据默认不落库；不改变工具授权、审批、锁与预算。
- 兼容性：旧客户端传 `modelProfileId` 仍可解析为快照；档案被忽略或凭据缺失时失败关闭。

## 验证与回滚

- 验证：061 的 A1–A11、`pnpm check`、`pnpm build`、相关 auth / prod E2E；真实凭据同步目录与一次思考工具调用。
- 回滚：迁移只加表与可空列，可保留数据回退代码；关闭目录接口不影响旧 Profile 读取接口（保留 deprecated）。

## 修订（2026-11-07，用户直接要求）

- 思考档位取消「默认」，固定为 关 / 低 / 中 / 高；新会话初始「中」。
- Provider 映射：`low`→`low`、`medium`→`high`、`high`→`max`（官方规范三档）；旧数据中的 `default` 读取时归一为 `medium`。
- 原文第 4 条“官方默认”与界面形态由本节替代：一级菜单为「模型 / 思考等级」，模型列表按 Key 名称分组，不使用滑杆；其余决策不变。
- 2026-11-07 PoC（真实 deepseek-flash）：同轮回传 / 省略 / 空串均可续跑，跨轮不带推理可用，流式适配器续跑完成；保留方案为仅 Turn 内存回传，不落库。
- 2026-11-07 用户确认思考过程可见：推理正文经临时 `assistant.reasoning.delta` 仅在当前 Turn 传输给已认证客户端；界面默认折叠，运行中只显示尾部单行预览，展开只显示计划与工具，不渲染完整思考，客户端不保留完整内容；不落库、不重放、不进日志/审计/跨模型上下文。

# ADR-026：开发期直接调整契约，撤回 IPC v2

- 状态：accepted
- 日期：2026-11-02
- 决策者：人类负责人（明确要求“撤回V2，删除本地的所有相关配置，直接按需求改”）
- 关联：I0-6；替代 ADR-025 中协议升级至 2 的条款，其余密码取消决策保持

## 背景与决策

项目尚在实现阶段，没有已发布客户端兼容承诺。初始化参数变化直接同步修改代码、契约与测试，统一重新构建；撤回本次 IPC v2，protocolVersion 保持 1，不新增旧参数适配、协议双栈或配置迁移。本机 Token、权限检查、参数严格校验和协议不匹配拒绝仍保留。

正式发布前，允许人类批准的破坏性契约调整，不因单次字段变化自动提升主版本；正式发布后再执行严格的协议版本管理。该约定不授权未来 Agent 自行清空数据或更改安全边界。

本次人类显式授权清理本机 Larness 配置及运行数据：确认停止实例后清理标准开发/生产数据目录与识别出的遗留测试数据目录，含配置、数据库、凭据密钥、配对/会话、日志。项目源码目录、依赖、浏览器全局数据不在清理范围；数据目录的 sessions/workspace 先检查，发现源码则保留。清理前展示路径和范围，不读取或输出秘密，不创建用户未要求的备份。

## 备选、影响与验证

- 保留 v2 或新增兼容层：当前阶段无必要，不采用。
- 清空源码/整个浏览器配置：超出授权，不采用。
- 保留初始化恢复、密钥校验、无密码向导与自动应用配置的修复。
- 测试 hello 返回 protocolVersion=1、无密码初始化及严格参数校验；pnpm check/build/真实构建 smoke。检查删除目标不存在，默认数据目录不会被测试重建。

## 回滚

代码可回退任务提交；本次数据删除不可通过 git 恢复，下次运行须重新初始化、配置模型凭据和配对。保留旧 ADR 为历史，以本 ADR 为当前协议决定。

# ADR-032 共享默认工作区

状态：accepted（2026-11-04，人类明确要求并选择共享默认目录）。

新未关联项目会话共用稳定目录，默认工作区入口在无需登记项目时提供文件与终端。复用 dataDir/sessions/global-terminal/workspace，兼容已有全局终端；旧会话路径 / 文件 / 项目均不搬移。替代 M1 中“每个新独立会话创建空目录”的行为，旧 ADR 原文不改。目录不是 OS 沙箱。

引入精确 workspace:default scope 和共享文件事件 / 锁域，权限只针对固定根，不扩大到其他运行数据。默认 AI 控制按会话授权根等值校验，不以 null projectId 判断资源归属；保留输入审批 / 租约 / 人工优先。新 Session DTO workspaceKind 仅展示用途，不授权。无迁移 / 新依赖 / 配置。回滚程序保留共享目录与已有记录，不删共享数据；旧代码不理解共享会话时失败关闭。

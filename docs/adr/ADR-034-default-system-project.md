# ADR-034 默认工作区作为固定系统项目
状态：accepted（2026-11-04，人类明确“默认工作区也是一个项目并且无法修改和删除”）。
默认工作区进入项目列表且置顶，是固定 ID / 名称 / 目录的内建系统项目。服务端返回真实目录描述 kind=default，更新 / 删除后端拒绝，前端无项目修改 / 移除操作。与用户目录登记项目共享导航和会话树，不创建可删除的伪登记行；不把“项目不可修改”扩展为内容只读。
保留 ADR-032 共享目录与旧默认 session / terminal 的 null 归属，默认资源 workspace:default / global 身份不迁移。prj_default 仅为项目描述与已支持资源的兼容别名，session / files / terminal 创建归一到既有默认域，避免旧窗口 / 事件 / 租约失联。历史独立会话不变。默认路径不能重复登记为普通项目。
只针对固定根使用既有默认目录授权，不放宽整个数据目录；PATCH / DELETE 服务层 FORBIDDEN。文件 / 终端 / AI 输入保留原权限、审批与审计。无 DB 迁移或新依赖。Git / dev 工具和 M3 范围不在本次扩展。
备选是迁移所有默认资源到普通项目 ID，会重写既有归属与事件 / 窗口身份，当前不采用。回退保留所有目录和资源，不删除用户数据；旧客户端可继续使用 workspace:default API。

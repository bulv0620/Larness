# ADR-040 完全自主审批策略
状态：accepted（用户 2026-11-04 明确要求“任何行为都不需人类审批”，选择时确认风险，授权恢复额度后实施）。
新增 autonomous 策略：已登记的 Agent 工具 L0–L3 在策略判断中均 allow，无逐次人工审批；其他三策略原行为不变。支持的能力与后端实际授权不扩展，不新增本机管理通道、特权或未实现系统动作。策略只在新 Turn 的持久 policy snapshot 固定，运行中不随 UI 改动；工具仍参数校验、真实客户端授权、项目范围、锁/fencing、幂等、取消/预算/审计/脱敏/人工输入优先，任何失败不自动放行。人工 Git 资源审批独立，不因 Agent 策略被绕过。
这补充 ADR-002/029 的逐次工具审批规则，仅在明确选择完全自主时免询问；标准/严格/只读及本机配对、安全管理等其他通道不变。用户主动选策略视为相应工具审批意图，执行仍关联原 policySnapshotId，不能将免询问解释为免授权。
UI 使用危险色盾牌；每次进入此模式前弹窗说明：Agent 可自行修改/删除项目文件、执行命令和推送等现有工具行为，不逐次确认，程序可具有本机账户权限且不是沙箱。取消不改策略，确认后下一轮生效，沿用输入框当前策略的内存选择，不写入持久化默认配置。风险在于不可预期操作，替代方案标准审批仍默认可选，用户明确选择全自主后按本决定执行。
无新依赖/DB列/迁移；现有字符串枚举扩展，服务端 DTO/API/快照验证、客户端类型同步。测试四策略风险矩阵、真实 authenticated API→Turn snapshot→工具执行、无审批但仍参数拒绝/旧策略不变、UI取消与确认。回滚改回标准并保留历史快照审计，不重写已有执行记录。

# ADR-055：npm 手动更新与数据库恢复

- 状态：accepted
- 日期：2026-11-09
- 审批：人类负责人于 2026-11-09 明确确认
- 关联：[宪法第十二条](../../CONSTITUTION.md#第十二条--更新安全)、ADR-007、[M5-3](../../specs/065-launcher-updater/spec.md)、[发布清单](../process/release.md)

## 背景

M5-3 已通过公共 npm 分发。TUI 查询 registry 并提示可用版本，用户运行 npm 安装命令。Server 在已有数据库需要迁移时先创建备份。宪法第十二条和 ADR-007 仍要求独立更新器、应用级签名校验、更新锁及自动回滚，与现有交付冲突。

## 决策

本决策修订宪法第十二条，并替代 ADR-007 的更新器、锁与回滚要求。

1. TUI 可查询公共 npm registry 并提示新版本。安装、升级、降级和重新启动由用户显式执行。
2. 发布由 npm 负责分发和安装。用户应等待 Agent Turn、部署及数据库写入完成，通过 TUI 正常停止管理面，再运行 npm 命令。维护中的 PM2 服务按现行独立生命周期处理。
3. 已有数据库需要迁移时，先备份再执行迁移。备份失败时拒绝启动。程序降级通过指定 npm 版本；旧程序发现更高 schema 时拒绝启动，由操作者按发布清单恢复匹配的数据库备份。
4. 信任边界为 npm registry、TLS 和发布账户。应用内签名验证、跨进程更新锁和程序自动回滚退出当前方案。发布与安装检查记录按平台和版本保留。

## 替代方案与风险

- 保留现行宪法条款并恢复独立更新器。需要另立实现任务，覆盖签名密钥管理、执行锁、恢复及三端验证。
- 采纳 npm 方案。发布账户或 registry 被攻破可影响分发；手动升级依赖操作者遵守停机流程。迁移备份是数据库恢复点，程序降级和数据库恢复需要分别执行。

## 迁移与回滚

DOCS-4 同步宪法、ADR 索引、发布指引和验收记录。程序降级与数据库恢复按[发布清单](../process/release.md)操作。未来改变分发或恢复机制须另立 ADR。

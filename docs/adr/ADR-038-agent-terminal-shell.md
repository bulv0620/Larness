# ADR-038 Agent 终端的 Shell 生命周期

状态：accepted（2026-11-04，用户获知现状后明确“对，这一层解决一下”）。

## 决策与授权
补充 ADR-029/033：新 Agent dev 终端也保留交互 Shell。初始前台命令被 Ctrl+C 中断、正常/异常退出后回到提示符；显式 stop / Tab 关闭终止整个 PTY 与受管后代。原始子命令不是终端资源本身，RUNNING 不能代表服务仍运行。只影响新建终端，不重启已有资源。

## 实现与安全
固定 /bin/sh -i 引导程序以位置参数接收批准 argv，在子 Shell exec -- 外部程序，父 Shell 捕获 INT 而子程序仍接收 INT。结束后 exec 已校验的账户 Shell -i，在原 PTY/PID 提供正常交互。参数不拼脚本，不经终端按键注入，不虚构人工或 AI 租约。后续输入沿用审批/租约；L2 启动批准范围/授权重验、白名单环境、HISTFILE=/dev/null、输出脱敏、同 role 复用、取消未交付清理与进程树确认保持。默认账户启动文件可信边界与人工 Shell 一致。

## 替代与风险
直接把服务作为 PTY 主进程无法在 Ctrl+C 后输入；自动重建 PTY 会改变资源 ID 并可能掩盖退出；把 argv 拼接/注入 Shell 引入解释和按键问题，均不采用。服务结束后多一个常驻 Shell，需要用户显式关闭；账户启动脚本可能改变环境/提示符，程序启动失败需读取原始输出，不能只凭终端状态宣称 ready。支持范围以实际 macOS 验证为准，无新依赖/迁移。

## 验证与回滚
真实 Ctrl+C 释放端口、同 ID 继续输入、参数字面传递、非零退出保留 Shell、显式关闭清理进程树、租约和审批回归。回滚仅影响后续新建资源；不强杀/重建现有终端、不删除数据。未来临时服务登记须核对真实子执行，不能只看 Shell 存活。

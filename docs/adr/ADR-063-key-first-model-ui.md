# ADR-063 · 模型管理与选择按 Key 分组

- 状态 `accepted`（2026-11-15，用户明确指定 Key 为第一层并要求实施）
- 部分替代 [ADR-062](ADR-062-model-connections-and-capabilities.md) 的界面入口与模型分组决策。连接身份、计费线路、目录与运行时约定继续适用。

## 决策

设置与会话选择器均在 Key 下展示模型。设置使用 Key 导航和当前 Key 的模型区，会话选择器用原位展开。收起后的会话按钮只显示模型名称及可用的思考档位。模型行显示能力图标、窗口短值及影响选择的提示。

## 取舍和回退

按模型合并会减少相同名称的条目。按 Key 分组会增加重复项，能在选择前直接确认所用额度，并将目录状态和维护操作放到所属连接。用组内搜索和紧凑行缓解列表长度。

只变更界面，沿用已有模型与凭据标识、掩码和接口。回退前端提交即可恢复先前界面，不需转换数据。

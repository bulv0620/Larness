# ADR-064 · 会话两级模型菜单与模型行右键操作

- 状态 `accepted`（2026-11-15，用户明确指定四项调整）
- 部分替代 [ADR-063](ADR-063-key-first-model-ui.md) 的会话展开方式。设置的 Key 主从关系继续适用。

会话菜单恢复两级，首层按顺序显示模型及思考强度。模型子菜单用小字 Key 标题分组，直接选模型；思考在自己的子菜单内调整。收起后只显示模型和适用的思考档位。

设置的行内操作收纳为模型右键菜单，名称后星标表示默认。保留能力和可见性按钮，原调用测试提供按行的进行中反馈。兼容平台放添加 Key 列表末尾。

保持 Key ID 与模型 ID 的绑定及隐藏模型的限制。只需回退界面提交即可恢复上一版布局。

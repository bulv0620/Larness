# ADR-054：定时任务的执行、权限与恢复边界

- 状态：accepted
- 日期：2026-11-07
- 决策者：人类负责人（2026-11-07 确认 M5-2 D1–D4）
- 关联：[064 spec](../../specs/064-scheduler/spec.md)、[064 plan](../../specs/064-scheduler/plan.md)、Q-009、ADR-002、ADR-040、ADR-050

## 背景

M5-2 需要让 Larness 在本机长期、无人值守地执行重复工作。与人工发起的 Turn 不同，定时任务没有操作者在旁边回答审批，且脚本任务本质上是任意代码执行。必须在以下方面固定边界，避免把“自动化”误解为“安全隔离”：

- 触发时间、时区、错过触发与重启恢复；
- 脚本与 Agent 两类执行的权限、环境和输出；
- 无人值守时的审批策略；
- 运行记录、保留、通知与失败关闭。

## 决策

1. **单进程、持久化调度**：调度器运行在 Larness Server 内，任务与运行存 SQLite；每 1 秒查询到期任务，在事务内创建 JobRun 并推进 `next_run_at`。不做分布式、多副本或独立守护进程。
2. **Cron 与间隔**：5 字段 Cron（分钟粒度），间隔 60 秒–7 天；每个任务显式保存 IANA 时区，默认系统时区；使用 `cron-parser@5.10.4`（纯 JS，传递 `luxon@3`），不自研 Cron / DST。春季不存在的本地时间不执行，秋季重复的本地时间只执行一次。
3. **错过触发**：默认 `skip`；任务可选 `run_once`，最多补 1 次。唤醒 / 重启后不批量补跑。`next_run_at` 以绝对 Unix 毫秒持久化。
4. **并发与超时**：同一任务不重叠，计划触发时若仍在运行则记录 `skipped`；手动立即执行返回 `CONFLICT`。全局同时运行上限默认 2，超出的运行排队。超时从进入 `running` 起算，默认 600 秒、上限 3600 秒；超时终止脚本进程组或取消 Turn。
5. **脚本执行**：内联源码存 DB，运行时写入数据目录下 0600 临时 `.mjs`，以 `node` 子进程在项目真实根目录执行，`shell: false`。环境只含白名单（`PATH` / `HOME` / `TMPDIR` / `LANG` / `LC_ALL` / `TZ` 与 job / run ID），不注入 Larness Secret Store、`LARNESS_*` 或 PM2 变量。输出合并、限长 64 KiB、先脱敏后落盘。**不声称沙箱**：脚本以 Larness 运行账户权限执行，可访问文件与网络。
6. **Agent 任务**：使用专用会话（`sessions.origin=scheduled`，默认不出现在普通会话列表），每次运行创建真实 Turn。任务只允许 `readonly` 或 `autonomous`；`standard` / `strict` 因无人应答审批而拒绝。默认 `readonly`，改为 `autonomous` 需二次确认；策略随 Turn 快照固定，运行中修改只影响下一次。
7. **通知**：仅应用内。JobRun 变化发 `workspace.jobs.changed` 系统通知（无序号、不携带正文），Web 重拉列表；失败角标来自 `failedLast24h`。不接系统通知、邮件、Webhook。
8. **恢复**：正常关闭把运行中的运行标 `cancelled`；异常退出后启动时把 `queued` / `running` 标 `interrupted`，不自动重跑；所有启用任务重新计算下一次触发。
9. **保留与审计**：每个任务保留最近 200 条运行且不超过 30 天；任务删除为归档，运行历史保留。审计记录任务增删改、立即执行、取消、启停，不含提示词 / 脚本 / 输出正文 / 秘密。
10. **限额**：最多 100 个任务；手动触发 10 秒限流；脚本 64 KiB、提示词 10 KiB、输出 64 KiB。

## 后果

- 定时任务能跨重启继续调度，行为可预测；不承诺毫秒级准时，最多约 1 秒轮询延迟。
- 脚本与 `autonomous` Agent 任务具有本机账户权限，属于显式授权的高风险能力；UI 与文档必须持续声明“不是沙箱”。
- 不自动重试，失败需人工处理；外部通知、任务依赖、重试 / 退避留给后续切片。
- Windows / Linux 的进程组终止与路径行为未在本 ADR 验证，归 M5-4。
- 新表与 `sessions.origin` 可空列只新增；回滚只能回退程序，数据库迁移不回退。

## 回滚

- 关闭调度：`LARNESS_SCHEDULER_ENABLED=false` 或禁用任务；立即执行仍可用于诊断。
- 脚本任务出问题：先禁用任务，再排查；不自动重跑。
- Agent 任务改为 `readonly` 可立即阻断写入类工具（下一次运行生效）。
- 旧版本程序忽略新表即可运行，但不会继续调度。

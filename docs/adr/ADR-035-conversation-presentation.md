# ADR-035: 紧凑对话流与底部审批
- 状态：accepted
- 日期：2026-11-04
- 决策者：人类负责人（多轮预览纠正后“就按照这个重构一版先”）
- 关联：specs/036-conversation-experience/spec.md

## 背景与决策
按已审批预览重构中央对话区：用户灰气泡、助手无气泡/头像；真实过程可折叠，计划与工具区分；审批在输入框正上方固定，消息仅摘要；资源浮栏紧凑，底部无说明文字栏。补充ADR-010/031的呈现，不改生命周期。复杂任务用真实update_plan元数据工具更新步骤，普通问答不强制计划。

## 备选方案
保留旧卡片堆叠被用户要求替换；独立轨迹Tab不采用。

## 影响、验证与回滚
无DB迁移/新依赖，既有授权、锁、审计不变。测试覆盖真实计划事件/重放、审批确认/失败、输入/滚动/资源回归。回滚相应任务提交，不删历史事件；旧客户端忽略可选字段。

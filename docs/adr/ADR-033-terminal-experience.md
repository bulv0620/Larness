# ADR-033 纯终端体验

状态：accepted（2026-11-04，人类在了解终端实现与界面问题后要求继续优化）。

人工 Shell 打开时自动申请一次空闲输入租约，成功后聚焦；另一人或 AI 正持权时不抢占。显式交出控制后不自动重新申请；点击内容 / Tab 菜单可重试，接管 AI 仍是独立显式动作。Agent dev 终端打开保持观察，避免查看输出影响 AI 执行。替代先点击“开始输入”的人工 Shell 界面，不改变后端授权、租约、AI L2 审批与人工优先级。

状态 / 控制工具栏从内容区移除，控制交接进入 Tab 菜单；终态、断线、输出缺口与操作失败仍提示。＋直接确认创建，风险确认仍逐次保留；重试复用同一键与 scope。双击 / F2 改名、× 关闭终止，窗口隐藏不终止。

人工 Shell 从本机 OS 账户资料读取默认 Shell，绝对路径、普通可执行文件检查失败则回退 /bin/sh；参数固定 -i，不接受浏览器 / 模型覆盖，不解释程序路径为命令，不继承完整管理环境，HISTFILE=/dev/null 保持。此前固定 /bin/sh 的替代为账户默认交互体验；账户启动文件可能影响提示符和初始化行为，这是本机可信执行边界内的行为，不是沙箱。无新依赖、REST / WS / DB 变更。

备选：保留常驻工具栏 / 固定 sh；不采用，无法满足人类要求的本地终端体验。验证双客户端、租约失败 / 过期 / 刷新、AI 显式接管及旧代拒绝、真实 PTY / 默认工作区与多 Tab。回滚仅回退界面与 Shell 选择代码，保留资源、目录和记录。

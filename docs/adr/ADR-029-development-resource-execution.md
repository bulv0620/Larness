# ADR-029：开发资源的执行、审批与锁边界

- 状态：proposed
- 日期：2026-11-02
- 决策者：待人类负责人确认
- 关联：[030 spec](../../specs/030-dev-resources/spec.md)、[契约草案](../contracts/m2-resources.md)、Q-021～Q-025

## 背景

M1 已有项目写锁和 Turn 审批；M2 加入任意主机进程、交互输入和无 Turn 的人工 Git 操作。输入租约不能证明进程已停止写盘；仅按 TTL 回收锁也不能阻止仍存活的旧子进程继续写。现有 approvals 要求真实 turnId / toolCallId，不能虚构 Turn 来审批人工动作。冻结 ADR-002/003/004 与宪法执行身份、事件、秘密和锁约束仍适用。

## 拟议决策（未经批准不实施）

1. **受管进程**：CommandRunner 与 PTY 使用 Larness OS 身份，只在声明范围解析 cwd；无 OS 沙箱承诺。环境白名单，不向任意命令 / PTY 注入 SecretStore 明文，不继承管理环境。L1 常规开发沿用项目策略，未知 / 显式 Shell 脚本 L2，L3 默认拒绝。
2. **锁（按 dev 场景修订，待批准）**：受管源码写作业仍持项目锁至结束；项目开发运行终端不长期占该锁，允许同项目前端 / 后端常驻与 Agent 编辑并行。开发终端和人工 Shell 可能产生非串行写，明确不在源码写锁保证覆盖范围内，使用监听 / 内容版本检测冲突；不宣称凭 cwd / 用途标记隔离写入。此例外需要人类明确批准对宪法第九条及 ADR-003 的解释 / 补充，批准前不改冻结原文或实现。不能把普通写任务包装为 dev 绕过审批；开发终端逐次 L2 审批。受锁写作业续租失败仍须先停止，未确认则阻塞冲突域。
3. **重叠根**：锁协调覆盖 canonical root 相等 / 祖先包含的范围；独立与全局 workspace 同样纳入，不允许不同项目 ID 绕过文件保护。多锁顺序沿用宪法，稳定排序获取，失败回退已取得的锁。
4. **人工 Git 动作**：新增资源动作记录，绑定真实客户端、参数哈希、仓库快照、有效期、单次消费和审计；不修改 M1 approvals 的必需 Turn 关联。Agent 走既有审批服务再调用同一 GitManager。pull / push 逐次审批；M2 仅 ff-only pull / 普通当前分支上游 push。
5. **依赖与 PoC**：沿冻结技术栈使用 node-pty，版本与原生资源寻址在 M2-0 记录，不安装未经批准的原生替代库。文件监听先用 Node 内置 API + 有界扫描对账，不新增 chokidar。真实 PTY、进程树清理、锁丢失 / 重启对账、文件路径竞争与监听溢出都须 PoC；失败不得把“仅命令输出”冒充终端完成。
6. **Agent 开发终端**：一次性命令用 CommandRunner，常驻前后端进程分别创建项目 PTY / Tab；Agent 工具支持启动 / 游标读输出 / 显式停止，不做通用 Shell 键盘自动化。按项目 + 用途复用活跃资源，参数不一致拒绝；创建成功交付后资源独立于 Turn，不随 Turn 完成 / 取消而结束。M3 再接服务登记、健康与预览；PTY 启动不等于服务 ready。
7. **输出**：状态事件先持久化再推送，输出独立有界游标；先脱敏再落盘。回放限额、过期缺口和慢消费者恢复见契约草案；不声称能识别任意未知秘密。

## 备选方案

| 方案 | 收益 | 问题 / 结论 |
|---|---|---|
| 仅输入时持项目锁，键盘空闲就释放 | 同项目多 PTY / Agent 体验更自由 | 无法证明旧命令已停写，与单写约束冲突，不建议 |
| 开发终端作为可能并行写入的主机进程 | 支持前后端 dev 与源码编辑并行 | 本次推荐提案；明确锁保证边界及版本冲突处理，待人类批准，不以用途标记宣称安全 |
| 每个执行任务使用隔离 worktree 或 OS 隔离 | 可支持更强并发语义 | 工作区合并、权限隔离超出 M2 范围，本期不采用 |
| 所有人工 Git 操作创建虚构 Turn | 少写动作表 | 混淆执行身份和历史，不采用 |
| node-pty 失败时仅保留 CommandRunner | 可减少原生发布成本 | 无真实交互终端，不满足现有 G2；只能在人类批准缩减范围后另议 |

## 影响、迁移与兼容

- UI：前后端分别为项目终端 Tab，来源显示 Agent；输入控制权与源码写锁分别显示；关闭窗口不停止资源，脏文件关闭需处理草稿。
- API / 事件：细化 files / terminals / git，增加命令、资源动作和关键事件补拉；保留既有认证与 Agent 序号语义。开发期协议号沿 ADR-026 保持 1，契约由人类评审后直接补齐，不添加旧草案字段适配。
- 数据：仅新增表 / 元数据，不破坏现有数据；复用 resource_locks，不更改已应用迁移。审批 / 锁 / 输出的变更与测试随各所属任务提交。
- 安全：任意脚本及 Git hooks 可访问主机；本提案收紧受管执行和可观测性，没有 OS 隔离保证。TUI 仍是唯一受管前台入口，退出停止全部。
- 支持范围：先验证实际 macOS 环境；其他平台按实机 PoC 公布，不推断支持。

## 验证与回滚

先通过 G-Spec-M2 设计评审，再实施 M2-0，G-PoC-M2 通过才实施文件 / 命令 / PTY / Git。验证受锁保护的旧写作业未停止时不能启动新写作业、重叠根写作业互斥；另验证同项目两个开发终端与编辑并行、用途复用与参数冲突、Turn 取消后的项目资源生命周期、审批参数不可替换、双客户端不能重放输入、真实发布物可用且退出无残留。

回滚时先排空 / 显式终止新资源，再回退代码；保留数据库新增表、日志和用户源码，不做破坏性 down migration。若关键 PoC 失败，保持受影响功能未开放，记录失败证据并请人类选择方案。

## 2026-11-02 评审修订

人类指出 Agent 启动前后端 dev 应在项目 Terminal 中分别创建 Tab。已据此补入 Agent 开发终端路径，撤回 PTY 存活期一律持项目锁的初稿建议；用户指出使用场景不等于已批准完整锁例外，ADR 继续 proposed。

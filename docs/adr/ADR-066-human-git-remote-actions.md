# ADR-066 · 人工 Git 拉取与推送

- 状态 `accepted`（2026-11-15，用户提出人工 Git 操作免重复批准，并要求按整体方案开始实现）
- 替代 [ADR-029](ADR-029-development-resource-execution.md#决策2026-11-02-按最新-spec-批准) 中人工 Git 拉取与推送必须逐次追加审批的规则。既有接口和历史动作沿用原状态机。

已认证客户端在 Git 面板明确点击「拉取」或「推送」，即提交对当前项目、当前仓库快照与对应上游的一次操作请求。后端校验 CSRF、客户端会话、快照和项目写锁，持久化请求并原子消费执行资格。复用既有 Git 执行器、参数和审计，远端能力仍限定为快进拉取和当前分支到上游的普通推送。Agent 工具走原有会话策略；设备授权和逐文件放弃更改走既有流程。

备选方案是保留审批并合并「批准」和「执行」按钮，仍会打断每次推拉。直接执行减少重复操作，风险在于上游选择错误和网络结果不确定。界面展示上游，后端验证已展示的仓库快照；重复请求仅查回同一动作，未知结果提示核对。外部进程仍可能修改仓库或 Git 配置，服务器沿用可信开发机边界。

复用现有表，无数据迁移。新接口与旧接口并行，可回退客户端入口。旧审批记录不转换为免审批授权。

# ADR-030：窗口、终端 Tab 与两类服务的生命周期

- 状态：accepted（产品规则；实现与技术门禁仍未通过）
- 日期：2026-11-02
- 决策者：人类负责人（本次会话连续明确纠正，并要求“补充和完善好文档”）
- 关联：[资源视图契约](../contracts/resource-views.md)、[服务与预览契约](../contracts/services-preview.md)、[M2](../../specs/030-dev-resources/spec.md)、[M3](../../specs/040-services-preview/spec.md)

## 背景与授权范围

人类明确：临时服务在 Terminal 中启动，服务模块只登记、展示和提供预览转发，不另管进程；持久服务由 PM2 管理，AI 与人都能操作。关闭 / 最小化窗口仅隐藏视图；关闭终端 Tab 就终止终端及其中服务。服务窗口没有服务 Tab，采用左上项目筛选、主体服务卡片、点击卡片看详情。

本 ADR 记录上述已明确的产品决定，不把文档授权扩大成实施授权。ADR-029 的写锁例外、依赖 / 平台 PoC、M2/M3 G-Spec、PM2 退出策略仍需各自门禁；不将整个 ADR-029 标记 accepted。

## 决策

1. **窗口**：关闭 / 最小化仅隐藏当前客户端窗口，保留 Tab、筛选和选择状态；切项目 / 刷新 / 网络断线也不触发资源终止。红色窗口关闭按钮不能遍历调用 Tab 关闭动作。
2. **终端 Tab**：用户主动关闭 Tab 即显式请求终止对应 PTY 及受管进程树，并使关联临时服务退登、预览失效。后端鉴权、幂等、审计和退出确认不可省略。等待期间显示正在终止；失败保留 Tab 和错误，不能先删 Tab 假装成功。输入租约不构成阻止已授权显式终止的权限。
3. **多客户端**：后端终止是全局结果。发起客户端在成功后移除 Tab，其他客户端显示 ended / unavailable，不能显示仍在运行；其他客户端本地布局不被强制清空。重复关闭 / 已结束资源的关闭幂等，不重新创建资源。
4. **文件 / 浏览器 Tab**：关闭结束相应编辑或预览内容；文件脏状态先处理保存 / 放弃 / 取消，不删除磁盘文件。浏览器关闭只销毁该页面，不停止被访问的服务或终端。Git Diff 关闭同属视图结束。
5. **临时服务**：由 TerminalManager 拥有进程生命周期。ServiceRegistry 绑定 terminalId、该次执行身份与实际 loopback endpoint，读取状态 / 关联日志，提供预览登记。注册不能 spawn 第二个进程，不经 PM2、不自动保活 / 重启。源进程停止即自动取消活跃注册；终端 Shell 仍存活也不能保留已退出命令的服务。终端终止撤销全部关联临时服务。
6. **持久服务**：构建产物的正式运行由 PM2Adapter 管理，保留配置 / 部署记录，经实际状态对账。人和 AI 通过同一后端服务能力启停 / 重启 / 读日志，身份、审批、锁及审计一致；不能让 Agent 直接绕过这些能力执行 PM2 管理命令。持久不等于自动证明跨机器重启可用；PM2 / OS 启动配置须实测。
7. **服务窗口**：无服务 Tab。左上“全部项目 / 指定项目 / 全局”筛选，主体为服务卡片，点击进入详情，返回列表；详情中的概览 / 日志切换不是服务资源 Tab。临时卡片提供详情 / 打开所属终端 / 打开预览，不独立启停或删除运行进程；持久卡片按权限提供 PM2 操作。关闭详情返回列表，不停止服务。
8. **结果入口**：文件工具结果可以附文件卡片，点击按 scope + 路径解析并打开文件窗口。临时服务登记成功且目标可用后可附预览卡片，点击凭 serviceId 解析隔离预览地址。卡片点击只打开视图，不启动进程、部署或把任意 URL 授权为代理目标。

## 替代 / 补充关系

- 替代 resource-views 2026-11-01 中“关闭终端 Tab 不终止 PTY”“每服务一个 Tab”的规则；保留资源归属、来源非授权、项目筛选、去重和客户端布局独立。
- 补充宪法第八条：Tab 是视图，但“主动关闭终端 Tab”是携带后端终止意图的显式操作；关闭 / 最小化窗口仍纯粹影响视图。终止必须审计，不能把前端卸载当作终止。
- 补充 ADR-012：开发临时进程由 TerminalManager 管理，ServiceRegistry 不再有独立 NativeProcessAdapter 启停职责；持久服务仍由 PM2 管理。原 ADR 索引与历史文档原文保留，以本 ADR 为对应条款的补充。
- 不改变 ADR-004 临时 PTY 不跨重启恢复、ADR-005 生产部署审批、预览隔离、认证准入和秘密规则。
- 不自动变更 ADR-023 的 TUI 退出策略。PM2 正式服务在 TUI 退出时是否保留是单独待决 Q-027，M3 持久服务交付前必须明确；不能从“持久”推断该项已批准。

## 影响与迁移

- 产品：M2 终端 Tab 关闭增加真实终止；M3 服务窗口改卡片 / 详情。S0 历史验收保持原记录，现有 Demo 代码不代表新规则已实现。
- 接口：Tab 不成为后端表；关闭 Tab 复用 terminate，临时服务登记与注销属于 M3。事件先持久化再广播，未知源进程 / 目标时预览失败关闭。
- 数据：服务区分 temporary / persistent、terminal 执行绑定 / PM2 标识；活跃退登不删除审计 / 历史记录或项目源码。具体表与字段仍为契约草案。
- 兼容：旧客户端布局的 service Tabs 迁移为服务窗口 filter / selectedServiceId；不得因布局迁移停止任何进程。不存在的资源显示失效，不自动重启。
- 本次只改文档，无依赖安装、运行代码、数据库迁移、数据清理或进程操作。

## 验证与回滚

M2 验证窗口关闭不 terminate、终端 Tab 关闭真实 terminate、失败保留 Tab、双客户端终态同步、文件 / 浏览器关闭无额外副作用。M3 验证一个终端多个 endpoint、命令退出但 Shell 存活、端口复用不串绑、退登即撤销预览、卡片无服务 Tab、PM2 人机同路及审批不可绕过。文档与实现完成分别验收。

实现回退不通过重新打开 Tab 启动资源；停止过的终端只能显式新建。若需要回退产品规则，新增 ADR，不静默恢复旧 Tab 语义。

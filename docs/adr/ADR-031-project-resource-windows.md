# ADR-031 项目窗口与终端交互

状态：accepted（2026-11-04，人类直接指定产品行为）。

窗口入口从 header 迁至聊天框上方项目浮栏；窗口按项目独立，无窗口内跨项目筛选。切项目只切视图，资源保持运行。关闭 / 最小化所有类型窗口均保留 Tab，可从浮栏恢复；主动关闭终端 Tab 仍 terminate。ADR-030 的生命周期与服务无资源 Tab 规则不变。取代 ADR-029 / resource-views 中全局窗口与项目筛选的展示规则，不改旧 ADR 原文。

人类要求 AI 完整接管项目终端，因此控制与读取允许同项目人工 Shell；保持 L2 输入 / 中断审批、显式租约和人工优先，不越项目、不抢人工持权。终端名称单独持久化，不复用 role。替代继续混合所有项目窗口的方案，避免误操作其他项目；代价是布局迁移拆分旧窗口。仅视图迁移，无进程动作。服务 / 预览后端仍在 M3。

# ADR-025：取消未接入使用流程的初始化密码

- 状态：accepted
- 日期：2026-11-02
- 决策者：人类负责人（本次对话明确选择“取消密码设置，保留历史哈希”）
- 关联：I0-4；补充 ADR-024 第 1 条的密码保留决定

## 背景与决策

管理员密码目前仅被哈希存储，没有验证或恢复消费者。首次初始化不再询问、接收或计算密码；本机 OS 权限与 IPC Token 仍是初始化和设备准入的信任边界，Web 无初始化/密码登录/密码恢复入口。

保留 auth_settings 表及历史 admin_hash，既有记录不更新、不删除。新实例在旧 NOT NULL 列写入空字符串作为“未设置密码”的兼容标记，不是可验证凭据；不虚构随机密码或哈希，不做破坏性迁移。initialized_at / auth_settings 单行继续标识实例初始化。

IPC init.apply 参数移除 adminPassword，网络字段变为可选补丁；旧客户端发送密码将返回 VALIDATION_ERROR。这是不兼容参数变化，本机 IPC protocolVersion 升为 2，TUI/server 随同发布，不提供静默兼容。无 REST/WS/Passkey 行为变化。

## 备选与影响

- 继续强制密码：增加负担且没有可用能力，不采用。
- 删除历史列/哈希：无必要且违反保留历史数据的要求，不采用。
- 新增密码恢复：超出本批范围，不采用。

移除无消费者的密码校验/Argon2id 依赖；保留日志秘密字段脱敏。更新安全文档、初始化契约与测试。未来若增加密码能力必须另立安全设计，空标记不可认证。

## 验证与回滚

测试无密码初始化、旧参数拒绝、并发唯一成功、历史哈希保持、Web 初始化拒绝，以及配对/Passkey E2E。旧版需要密码的新实例不能直接降级到旧初始化向导，回退前须使用备份与对应版本；不清空历史数据。

# ADR-041 Git 逐文件放弃与取消暂存
状态：accepted（2026-11-05用户直接要求新增这两个动作）。
逐文件放弃更改经UI显式确认后，tracked恢复工作区到index、保留stage；untracked仅删除该普通文件。取消暂存仅调整index到HEAD（无HEAD则移除index条目），不动工作区；rename同时恢复原路径index。此为用户主动发起的单文件恢复/删除授权，不是默认清理源码，不扩展为全仓库reset/clean、递归删除/强制覆盖。既有项目移除仍只解除关联，宪法其他数据保护规则不变。
复用资源动作鉴权/CSRF/锁/审计/快照/幂等，discard要求confirmed:true并绑定目标内容哈希；拒绝目录、符号链接、子模块、冲突和非普通文件。使用无Shell Git和literal pathspec，避免通配符扩张；外部进程不在项目写锁隔离内，不宣称无TOCTOU。暂不新增Agent工具。替代：伪造前端按钮或全仓reset均不采用。风险为丢失未提交内容，确认框告知路径和不可恢复后果；取消不执行，操作失败不隐瞒。
无依赖/迁移/新增REST路径，现有action枚举扩展。真实临时仓库验证分层修改/新文件/unborn/特殊路径/失败/快照与锁；回滚仅移除入口/新动作，不改历史或恢复已丢弃内容。

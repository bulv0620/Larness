# ADR-036: 对话区复用外围视觉语言
- 状态：accepted
- 日期：2026-11-04
- 决策者：人类负责人（明确要求保持结构、样式与外围统一）
- 关联：specs/037-conversation-theme/spec.md

## 背景与决策
M2-15黑灰主操作和独立白底与外围风格割裂。保留ADR-035结构/交互，修订其灰色用户气泡和纯中性色方向：复用既有浅灰canvas、淡蓝用户消息、accent主操作、语义状态色、柔和阴影和共享按钮。所有颜色沿用已有token，不改全局主题，不新增大卡片/头像/常驻提示。

## 备选与影响
全部保持黑灰不满足用户要求；修改外围风格超出本任务。仅前端视觉，无契约/DB/依赖/权限变化。

## 验证与回滚
浅/深/320px浏览器验收与既有组件/流程回归；回滚本任务提交即可，不影响数据或资源。

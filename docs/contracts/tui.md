# TUI 页面与输入契约

> 状态：accepted（2026-11-02 人类指令开始实现）；配套 specs/016-tui-experience/spec.md、ADR-027。未实施，不覆盖当前 I0-7 行为。IPC protocolVersion=1，传输和权限继续以 ipc.md 为准。

## 页面结构

页头显示 Larness、当前页面与必要状态；正文只绘制当前页面；底部固定显示可用按键、加载/错误和返回目标。独立屏幕覆盖启动、初始化、日常操作与退出确认；离开 TUI 恢复原终端。

控制面板入口顺序：配对、设备、日志、审计、退出并停止服务。默认选配对；p/d/l/a 可直接进入对应页，q 只在概览打开退出确认；不保留重复的 s 关闭 server 菜单。

| 页面 | ↑/↓ | Enter | Esc | 其他键 |
|---|---|---|---|---|
| 概览 | 选择入口 | 打开选中入口 | 保持概览 | p/d/l/a 快捷入口，r 刷新，q 退出确认 |
| 配对列表 | 选择申请 | 打开申请操作 | 概览 | r 刷新 |
| 配对操作 | 选择允许本次/始终允许/拒绝/返回；只显示可用项 | 进入二次确认或返回 | 配对列表 | 禁用不支持的始终允许 |
| 配对确认 | 选择确认/取消，默认取消 | 提交一次或取消 | 配对操作 | 请求发出后暂停重复业务按键 |
| 配对码 | 无业务动作 | 清空码引用并返回概览 | 清空码引用并返回配对列表 | 无刷新/重新生成/复制到日志动作 |
| 设备列表 | 选择设备 | 详情 | 概览 | r 刷新 |
| 设备详情 | 滚动 | 未撤销设备进入撤销确认；已撤销无动作 | 设备列表 | r 重新加载详情（通过 devices.list） |
| 撤销确认 | 选择确认/取消，默认取消 | 提交一次或取消 | 设备详情 | 成功/失败结果回详情停留 |
| 日志 | 滚动当前来源正文 | 无动作 | 概览 | ←/→ 切换来源，r 刷新快照，PageUp/Down、Home/End |
| 审计 | 滚动摘要正文 | 无动作 | 概览 | r 刷新，PageUp/Down、Home/End |
| 退出确认 | 选择确认/取消，默认取消 | 停止全部或取消 | 概览 | 无快捷直接确认 |
| 初始化文本输入 | 文本编辑 | 提交当前字段 | 取消当前步骤；首步取消结束本次初始化并停止受管服务 | q/r 为普通文本，Ctrl+C 保持全局停止 |

全局 Ctrl+C 停止 Server/Web；SIGTERM/SIGHUP 同样清理。独立屏幕中不输出原始日志或异常控制序列。只读加载可返回，写请求在途的 Esc 不代表取消，超时转“结果待确认”。

## 页面数据与上限

| 页面 | 读取来源 | 快照/刷新 |
|---|---|---|
| 概览 | system.status；地址来自有效配置/supervisor | 进入时、r 手动刷新；不默认读取 audit.tail |
| 配对 | pairing.list(status=pending) | 进入和 r；按 requestId 保持选择；写操作由 approve/deny 完成 |
| 设备 | devices.list | 进入、r 和操作结果后的显式加载；按 deviceId 归属，撤销方法不变 |
| 日志 Server | logs.tail(lines=200) | 使用既有最大 500 行限制；进入和 r 请求 |
| 日志子进程 | supervisor 现有缓存，最后 300 行 | 与 Server 一起取本机快照，来源切换不请求；无该来源时显示不可用说明 |
| 审计 | audit.tail(limit=200) | 最新记录优先，字段取现有时间/动作/结果/资源摘要；进入和 r |

手动刷新不跳页；列表按资源 ID 保持选择，已删除项选最近有效项。阅读页第一次进入日志定位末尾，默认 Server 来源；审计定位最新记录。日志刷新前在末尾则刷新后仍在末尾，否则维持视觉行偏移并 clamp；审计在顶部则保持最新记录，否则维持偏移并 clamp；日志来源各自保存偏移。旧快照刷新失败时保留并显示旧数据标记，首次失败与真实空态分开。

## 输入、尺寸与请求竞态

- 最小完整布局 80×24；100×30 验证正常，60×16 验证空间不足态。正文可滚动，页头/操作提示固定；长地址/中文/emoji 使用显示列宽计算而非字符串长度。
- 小尺寸暂停业务输入，只允许 Esc/Ctrl+C；resize 恢复原页面。处于写请求在途时 Esc 仍不可取消写入，结果先更新状态，恢复尺寸后展示。
- 每次页面加载带本机递增请求代号；返回/切页使旧代号失效。晚到只读结果不得渲染到新页面；不要求改变 IPC request.id。
- 请求 5 秒超时；最多 2 次重连，沿用现有连接生命周期与 5 分钟保活。重连不自动重放写请求，旧确认失效。
- 写请求超时显示结果待确认；下次由用户手动读状态。批准可能成功但未收到码时不调用 approve 重取或延期，提示浏览器重新发起申请。
- 初始化/确认和菜单不得同时监听 stdin；输入 q 不触发退出，Esc 不提交字段。全局停止始终可用。

## 展示与秘密

服务端和外部输入文字先过滤 ANSI/OSC 等控制序列，再由本机渲染器添加受控样式；保留正文换行，制表符转为空格。禁止外部文本设置终端标题、光标或链接。

配对码只保存在当前本机页面状态，离页释放引用；不进入最近操作、日志、审计、错误或真实秘密测试快照。页面截图和终端自动化只用假码/假密钥。独立屏幕不是安全擦除终端此前历史的机制。

退出停止含义与 ADR-023 一致，当前传输/存储/权限契约没有变更；此文档仅定义后续 TUI 展示交互。

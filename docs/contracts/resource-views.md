# 资源、项目窗口与 Tab 归属契约

> 状态：accepted，2026-11-02 按 [ADR-030](../adr/ADR-030-resource-lifecycle-and-services.md) 修订。适用于 M2 及后续真实资源；S0 旧 Demo 尚未按本修订实现，不回写历史验收结论。

## 2026-11-04 当前展示规则（ADR-031 / M2-9）

本节取代下文历史 V1–V4 的全局入口、跨项目窗口和筛选展示规则，生命周期与后端授权不变。

- header 不再提供资源窗口入口；项目右栏仅文件与 Git。
- 聊天输入框上方浮栏提供终端、临时开发服务和已隐藏的文件 / Browser / Diff 窗口。开发服务采用卡片 / 详情，无服务资源 Tab。正式服务在 M4 由左侧「服务运维」展示。见 [ADR-047](../adr/ADR-047-service-operations-entry.md)。
- 窗口按 kind + projectId 独立；无项目时按 workspace session 区分。窗口内无项目切换 / 筛选器。左侧切项目只切可见视图，返回保留窗口位置、Tab、激活、草稿及最小化状态，不启停资源。
- 所有类型窗口关闭 / 最小化均隐藏并保留 Tab，从当前项目浮栏恢复。主动关闭 Tab 仍执行下文类型对应的生命周期；关闭终端 Tab 必须等待后端确认退出。
- 同项目同资源去重；重叠项目相同 realpath 可各有文件视图，共享内存文件模型和版本，不把草稿复制到 localStorage。
- Tab 固定 32px 行高，横向滚动不显示占位原生滚动条；溢出时提供左右按钮、滚轮和键盘访问，激活 Tab 自动滚入视野。
- 终端 Tab 可双击 / F2 改名；名称是后端共享资源字段，不是 dev role。新建按钮创建项目 cwd 的 Shell；窗口恢复只枚举和恢复视图，不创建进程。
- 用户可释放输入交给 AI；AI 可读取 / 控制当前项目空闲 Shell 或 dev 终端，仍逐次审批输入 / 中断、不抢人工持权。人工可显式接管 AI。
- 导航只在服务器快照成功后核对；有效项目与草稿身份持久化，刷新不自动切到其他最近会话，不保存草稿输入正文。
- 布局版本 v4 从混合窗口按项目 / 类型拆分，保留原 Tab、bounds 与最小化状态，不调用进程接口。

## 2026-11-04 默认工作区补充（ADR-032 / M2-10）

未选项目时进入默认工作区（左栏固定入口），不是伪项目。新未关联会话共享目录、文件、终端视图组 `global`；无项目草稿也使用相同视图组。旧独立会话通过 Session DTO.workspaceKind=session 区分，保留自己的 session 视图组和源目录，不与默认混合。默认文件使用 workspace:default scope；默认终端 session 归属为空，切默认会话 / 草稿、具名项目再返回、刷新均恢复相同资源 ID。所有 scope 后端核对，不凭视图分组授权。

## 1. 原则

- 资源全局、视图本地；来源、项目筛选、Tab 标签都不是授权依据。
- **关闭 / 最小化窗口只隐藏视图；主动关闭终端 Tab 就终止对应终端和受管进程。** 刷新、卸载组件、切项目、断网、布局迁移不能触发 Tab 关闭命令。
- 终端、文件、浏览器、Git Diff 使用 Tab；**服务窗口不使用服务 Tab**，采用项目筛选 + 卡片列表 / 详情。
- 同资源重复打开优先恢复 / 聚焦，不重复创建后端资源。多客户端各自保存布局，后端资源状态共享。

## 2. 身份与来源

| 类型 | 资源身份 / viewKey | 展示结构 |
|---|---|---|
| Terminal | `terminal:<terminalId>` | 每 PTY 一个 Tab；主动关闭触发 terminate |
| Service | `serviceId`（卡片 / 详情选择键，不是 Tab key） | 筛选后的卡片列表，点击服务进入详情 |
| Browser | `browser:<serviceId>:<normalizedUrl>` | 每登记服务 + URL 一个页面 Tab |
| File | `file:<realpath>` | 同 realpath 跨项目 / 来源复用 Tab |
| Git Diff | `diff:<projectId>:<path>` | 同项目同文件复用 Tab |

Browser URL 归一化：host 小写、去默认端口、解析点路径、保留 path/search、忽略 hash；身份归一化不授权任意 upstream。文件必须先通过后端 scope 授权才能返回 realpath。独立会话来源展示“独立会话”，不因 projectId=null 扩大权限。

```ts
type OriginType = "global" | "project" | "session" | "agent" | "artifact";
interface ResourceOrigin {
  type: OriginType;
  projectId: string | null;
  sessionId: string | null; // 来源，不是授权
  label?: string;
}
interface WindowTab {
  id: string;
  kind: "files" | "terminal" | "browser" | "git-diff";
  resourceId: string;
  viewKey: string;
  title: string;
  projectId: string | null;
  origin: ResourceOrigin;
  createdAt: number;
}
type ProjectFilter =
  | { mode: "all" }
  | { mode: "global" }
  | { mode: "project"; projectId: string };
interface ServiceWindowView {
  filter: ProjectFilter;
  selectedServiceId: string | null; // null=列表；非空=详情，不是 Tab
}
```

Tab 标签显示“项目名 · 资源名”，null 项目显示“全局”或“独立会话”。真实资源归属取后端，不取当前左侧项目；同 realpath 跨来源打开只更新展示上下文。同一窗口 Tab 按项目分组，组按首个 Tab 创建时间排序，组内按创建时间，新 Tab 插组末尾；聚焦 / 筛选不重排。

## 3. 打开、筛选与恢复

| 操作 | 行为 |
|---|---|
| 首次顶部入口 | 默认全部项目，展示资源选择 / 空态；不自动新建终端或服务 |
| 再次顶部入口 | 恢复窗口、上次 filter、activeTabId；服务窗口恢复 filter / selectedServiceId |
| 项目内文件 / 终端 / Diff 入口 | 筛选对应项目并激活已有 Tab 或新增视图，不重复创建资源 |
| 项目内开发服务卡片 / 临时服务结果入口 | 打开开发服务窗口，按项目选择 serviceId 详情，不创建服务 Tab |
| 切换左侧项目 / 会话 | 不改变已开窗口筛选和内容，不停止资源 |
| 筛选隐藏当前激活 Tab | 选可见的第一个，无可见项显示空态；资源仍运行 |
| 显式打开被筛选隐藏的资源 | 切到相应项目 / all，目标可见并聚焦 |
| 同 browser 服务 + URL | 聚焦已有页面 Tab；不同 URL 可以新建页面 Tab |
| Agent 一次性命令 | 对话命令卡片，不创建 Terminal Tab |
| Agent 启动 dev 终端 | 发起客户端增加 origin=agent 的项目 Terminal Tab，不抢焦点；其他客户端只更新资源列表 |
| Agent 登记临时服务 | 聊天服务浮窗更新临时服务列表，不插入服务 Tab，不强制弹窗 |
| Agent 发布正式服务（M4） | 「服务运维」更新正式服务列表，不插入聊天服务浮窗，不强制切换页面 |
| 文件结果卡片 | 点击按 scope / path 解析并打开文件 Tab，不重新执行工具 |
| 预览结果卡片 | 点击按 serviceId / 相对页面路径解析预览，再打开 Browser Tab；不启动服务 |

会话中的成果区和单独产物在所属 Turn 结束后显示。取消、失败或中断后可查看已产出的结果。

终端 / 文件 / 浏览器的筛选控件与 Tab 同排：下拉最左、Tabs 横向滚动、计数最右。服务窗口左上项目筛选，主体卡片列表，开发服务卡片注明状态、项目、地址和来源；点击详情后提供返回列表。详情的日志 / 信息子区不承载独立服务资源 Tab。

服务列表与详情是 Query 服务器数据，客户端只保存 filter / selectedServiceId / 布局。临时服务退登后从活跃列表移除，已打开详情显示已结束 / 不可用并可返回。正式服务停止后在「服务运维」保留 stopped 和发布历史。关闭详情不停止任何服务。

## 4. 生命周期与失败处理

| 操作 | 后端影响 | 客户端结果 |
|---|---|---|
| 关闭 / 最小化窗口 | 无资源终止请求 | 保留内容 / Tab / filter，隐藏窗口，顶部恢复 |
| 主动关闭运行中的终端 Tab | 已认证、幂等 terminate，终止 PTY 和受管进程树；M3 撤销关联临时服务 / 预览 | 显示 stopping；确认终态后移除发起者 Tab |
| terminate 失败 / 会话失效 | 拒绝或保持待确认，不能伪报停止 | 保留 Tab、状态和可恢复错误；网络超时先查终态，不自动新建 |
| 关闭已结束终端 Tab | 无需重杀，幂等核对终态 | 移除本地结束视图 |
| 关闭文件 Tab | 不删除文件 | 脏文件保存 / 放弃 / 取消；保存失败保留草稿和 Tab |
| 关闭 Browser / Git Diff Tab | 不停止源服务 / 终端 | 销毁该页面或差异视图 |
| 关闭服务详情 / 窗口 | 不停止服务 | 返回卡片列表 / 隐藏窗口，无服务 Tab 关闭操作 |
| 在「服务运维」显式停止正式服务（M4） | 经策略授权调用PM2Adapter；人工仅按策略需要，自主免人工；持久状态与审计 | 所有客户端更新 stopped；保留配置 / 部署记录 |
| 临时服务需要停止 | 从卡片打开所属终端，在终端中断进程或关闭终端 Tab | 源进程退出后自动退登，卡片 / 预览失效；服务模块不独立控制它 |

最后一个 Tab 关闭成功后可以隐藏空窗口；这不改变之前已完成的终止 / 草稿处理，也不因空窗口恢复新建资源。

一个终端可关联多个临时 endpoint，关闭其 Tab 会影响全部关联服务；界面显示影响范围，不能只关一个 endpoint 却声称终端仍可用。是否存在关联服务由后端判断，不能只看当前浏览器已打开卡片。

刷新 / 浏览器退出 / 连接中断只断开视图和输入租约，不逐个关闭 Tab。布局恢复先查询后端，ended / interrupted / missing 不重建进程。旧 service Tabs 迁移成服务窗口筛选与选择，不执行启停。Larness 重启不恢复临时 PTY；临时服务先撤销，PM2 持久服务依实际对账恢复展示。TUI 退出与重开策略见 [ADR-046](../adr/ADR-046-pm2-delivery-and-lifecycle.md)。

## 5. 多客户端、权限与审计

- 一客户端主动关闭终端 Tab 是全局终止；其他客户端显示已结束并停止输入，保留自己的结束视图直至关闭，不误报运行。
- 一客户端关闭窗口 / 文件 / Browser Tab 仅影响本地视图；服务卡片列表是共享状态的查询结果，布局仍独立。
- 终端输入同时只给一个控制者；终止资源是独立授权能力，不能从“无输入租约”推断禁止显式终止。
- 所有卡片解析、订阅、读取、终止、服务动作、预览均后端授权；origin 仅来源。资源 / PID / URL 不由前端随意指定。
- 窗口隐藏、文件 / Browser Tab 关闭可记本地调试；终端 Tab 关闭的 terminate、服务登记 / 退登 / PM2 动作、预览授予 / 拒绝必须审计。不记录输入正文、秘密、票据或敏感 URL query。

## 6. 验收场景

| ID | Given | When | Then |
|---|---|---|---|
| V1 | 终端筛选全部 | 从项目 A 右栏打开终端 | 筛选 A、激活目标；B 终端仍运行 |
| V2 | 窗口有布局历史 | 关闭 / 最小化窗口后顶部恢复 | 原 filter / Tab / 激活恢复，PTY 不重复创建；首次默认全部 |
| V3 | 终端窗口筛选 A | 左侧切项目 / 会话 | 已开窗口筛选与内容不变 |
| V4 | 已有 A / B Tab | 重复打开 A，或新建 A 终端 | 复用原资源；新 Tab 插 A 组末尾，不重排 B |
| V5 | 同一运行 PTY 两客户端查看 | 一方主动关闭终端 Tab | 后端终止，发起方成功后移除 Tab，另一方 ended，临时服务退登 |
| V6 | 服务窗口有 A / B 卡片 | 筛选 A | B 卡片隐藏但继续运行；无服务 Tab |
| V7 | PTY 终止失败 / 超时 | 关闭终端 Tab | 保留 Tab / 错误，核对真实状态，不假装成功 |
| V8 | 前后端两个终端，各有临时服务 | 关闭前端终端 Tab | 仅前端终止 / 退登；后端继续；关闭整个窗口均继续 |
| V9 | 服务列表或详情可见 | 关闭详情 / 服务窗口 | 不停止服务；顶部恢复筛选 / 选择，无 Tab |
| V10 | 脏文件及运行服务预览 | 分别关闭文件 / Browser Tab | 文件按保存选择处理，源文件 / 源服务不被删除或停止 |
| V11 | AI 结果附文件 / 预览卡片 | 重复点击 | 授权解析后复用相应视图，不重复执行命令或登记服务 |

## 7. 非目标

不跨客户端同步布局，不以筛选授予权限，不代理任意第三方 URL，不在窗口恢复时自动启动资源。实现任务、平台与安全门禁仍由 M2 / M3 spec 决定。


## M2-2 文件接线（2026-11-03）

文件视图已接真实 API，身份为 kind=files + 已授权 realPath，同身份跨 scope / 来源复用；scope / path 仅作为重新鉴权读取的目标。文件窗口 close / hide 均保留 Tab 和内存草稿，主动关闭脏 Tab 通过保存 / 放弃 / 取消处理。模型按文件独立保留，Tab 真正移除后释放；完整文本不进入持久布局。工具文件结果卡片不重执行修改，精确失败 / 合并语义见 [m2-resources §13](m2-resources.md#13-m2-2-编辑器与文件结果2026-11-03)。其他资源接线仍按后续任务实施。

## M2-4b 终端接线（2026-11-03）

真实终端入口枚举既有资源，创建必须确认主机执行风险；窗口隐藏/关闭保留 Tab，刷新重新读取同一 terminalId，不恢复输入权。Tab 主动关闭等待已确认终态后移除；失败或停止不确定保留视图。另一客户端同步终态且保留自己的 Tab。列表/当前状态为 Query 数据，输出与租约不写入布局。Agent 创建工具和不抢焦点的自动 Tab 接线继续属于 M2-4c。

## M2-11 终端交互补充
终端内容只展示交互与异常；活动 Tab 条上的操作菜单提供交给 AI / 接管控制 / 输入终端，双击 / F2 改名，× 关闭并终止资源。空闲人工 Shell 首次打开自动申请一次租约，交出后不抢回；Agent dev 保持观察。＋直接打开逐次风险确认，无中间列表 Tab。租约只在当前视图内存，服务端状态仍由 Query 维护。

## M2-12 右侧资源区
右侧文件 / Git 上下分区直接展示，移除全部 / 文件 / Git 视图 Tab，保留折叠、拖动、双击均分及键盘调整。Git 不可用显示简短灰色占位，未选择项目 / 非仓库不展示写操作控件。文件树移除常驻连接状态与刷新行，订阅 / 补拉 / 自动重连保留；空根目录显示灰色占位，实际读取失败仍可重新加载。实际 Git 动作失败、文件冲突和权限拒绝继续明确反馈；REST / WS / 数据与授权不变。

## M2-13 固定默认项目
默认工作区在项目树内置顶，固定 ID prj_default / 名称 / 目录，不提供项目修改或移除菜单；项目服务层同样禁止修改和删除。可正常折叠、搜索、新建与管理会话、编辑文件和使用终端。为兼容已有默认视图，导航 / Session / Terminal 的 null 归属及 global 窗口 scope 保留，默认 FileScope / WS 身份仍 workspace:default；项目 ID 只为这些既有资源提供 HTTP 别名，不重建已有资源。普通项目操作及旧独立会话归属不变。

## M2-20 终端空态与历史入口（2026-11-04）
按用户确认，空窗口仅展示新建与RUNNING终端恢复入口，不默认枚举已结束历史，内部terminal:empty不作为可见Tab。聊天结果和运行资源恢复点击前强制读取鉴权GET `/api/terminals/:id`，核对ID/项目，RUNNING才打开原ID；已确认终态提示已关闭、404提示已关闭或清理，其他失败可重试，停止不确定不宣称已退出。读取不创建/重启PTY，历史事件/输出接口不删除，关闭/最小化窗口仍只影响视图。列表分页历史不会阻挡发现后页运行资源。

## M2-21 Agent 显式关闭终端（2026-11-04）
Agent 经授权成功停止终端后，发起客户端根据持久化关闭目标再次读取状态，确认停止后同步移除目标 Tab（含最小化 / 非激活 / 非当前项目视图），浮栏计数随现有视图 store 更新，最后一个 Tab 移除后收起窗口。停止失败、状态不确定或查询失败保留；其他客户端保留自己的结束视图。自然退出没有关闭目标时保留日志视图。聊天历史入口继续按 M2-20 提示已关闭，不重建终端。

## M2-22 Agent 终端 Shell 生命周期（2026-11-04 / ADR-038）
新建 mode=dev 终端由 Shell 承载初始批准程序；Ctrl+C / 程序正常或非零结束后，在同一 PTY / terminalId / PID 进入账户默认交互 Shell。Tab 保留，终端保持 RUNNING，人工可继续输入，AI 仍按原租约 / 逐次审批输入。RUNNING 只表示终端存活，不证明服务进程或 endpoint 仍在运行；服务失败/不存在通过原始输出核对，不能以创建成功宣称 ready。
显式 stop_project_terminal / Tab 关闭仍终止整个终端和受管后代，确认后按 M2-21 移除发起客户端视图。窗口隐藏 / 最小化 / Turn 结束不停止资源。自然 Shell exit 才产生 terminal.exit 和终端退出码；初始程序返回值不再冒充终端退出码。
已有资源不迁移/重启；同 role 同参数仍只复用终端，不重新执行初始命令，Agent 需先读输出、再通过批准输入在原终端启动所需命令，不得绕过人工持权。初始命令的 executable/args/cwd 与去重/幂等/审批绑定保持，shell 字段对新资源表示后续交互 Shell，旧行保留原值。
实现采用固定 /bin/sh 交互引导脚本与位置参数：子 Shell exec -- 执行外部程序，父 Shell 捕获 INT，子命令正常接收 INT；随后 exec 已校验账户 Shell -i。不拼用户脚本、不注入按键或伪造租约。环境过滤、HISTFILE=/dev/null、输出脱敏、取消清理、未知停止隔离仍保留。无新接口 / 事件字段 / 数据迁移 / 依赖。未来临时服务必须核对真实子执行，不能仅看 PTY RUNNING。

## M2-24 文档窗口关闭
按 ADR-039，files/git-diff/browser 红色关闭请求关闭当前全部 Tab，多 Tab 先确认，文件草稿逐项保存/放弃/取消，失败保留；不删除文件/停止预览服务。最小化继续保留并动画到浮栏（减少动态偏好跳过），terminal/services 关闭仍隐藏；切项目/卸载不触发关闭。关闭请求只针对用户确认时已有 Tab，新收到视图不被顺带关闭。

## M2-26 侧栏与 Git 呈现
文件/Git互斥展开，可全部折叠，flex过渡、reduced-motion兼容，折叠不终止文件监听或丢弃当前 Git 输入/审批。Git顶部提交区（按钮仅提交已暂存）、已暂存/更改目录树、行暂存显式路径和Diff，底部推/拉/分支/刷新；分支表单按需打开。项目切换按key隔离临时表单/异步结果，不把A项目操作应用到B。沿用原真实动作/快照/审批/错误；不自动暂存所有文件、不伪造撤销/取消暂存能力。此规则取代 M2-12 的同时展开/分隔线调高展示，API/授权/数据不变。

## M2-27 Git 单文件恢复与取消暂存（ADR-041）
现有 Git resource-action 接口新增 `{ action: "unstage", paths: string[] }`（1–200条精确路径）及 `{ action: "discard", path: string, confirmed: true }`（单文件）。动作仍按 L1 复用已鉴权/CSRF 的创建和执行、项目锁、快照重验、过期、审计与幂等，无新增路径/DB列/依赖，不注册新 Agent 工具。
unstage仅恢复选定index到HEAD；无HEAD使用仅index移除，工作区不变；重命名同时恢复原路径index。discard仅处理未暂存变更，tracked从index恢复工作区，已暂存内容保留；untracked经确认后仅删除指定普通文件，不递归、不含忽略文件、不清理全仓。冲突、目录、symlink/非普通文件及越界拒绝。Git以字面pathspec执行，通配符不扩张。
discard动作创建时和执行锁前/锁后读取目标内容哈希，发现后续内容或状态变化拒绝覆盖；外部进程仍不受项目锁隔离，不宣称OS原子性。untracked枚举使用--untracked-files=all，文件逐条呈现而非目录清理。UI放弃按钮先显示路径与丢失/删除后果，取消不创建写动作，确认后才调用；取消暂存无丢弃确认，因为它保留磁盘内容。编辑器内存草稿不自动删除，监听/版本冲突继续保护。

## M2-28 Git 反馈精简
Git不可用仅简短灰色占位，不显示重试按钮，原自动查询/恢复继续。刷新或写操作的忙状态复用工具栏刷新图标旋转、按钮禁用及aria-busy，不添加整行“正在处理”导致布局跳动。真实动作错误、状态读取失败/旧数据禁写和审批仍明确展示；API/权限无变化。

## ADR-042 服务阶段与策略（2026-11-05）
M3 当前项目浮窗显示临时开发服务的登记、日志与预览，源进程由终端控制。M4 的正式 PM2 服务和发布记录从左侧「服务运维」查看和管理，访问入口不依赖当前聊天或项目。隐藏浮窗或离开运维页均不启停服务。部署和服务Agent业务动作在autonomous下无人工审批/操作确认，普通策略需要时才出现输入框上方审批；自主仍显示真实步骤/结果/失败，不制造批准记录。M3-5/5b已迁至M4-0/3/3b；原历史V1筛选/固定人工部署描述以最新ADR-031/039/042为准。

## M3-11 工作区前端交互

点击资源浮窗外的工作区时，当前范围内未置顶的可见浮窗缩小至浮栏，置顶窗口保留。黄色按钮可手动最小化置顶窗口。动画期间重新打开会取消该窗口的动画，开启减少动态效果时直接隐藏。最小化隐藏当前项目中已挂载的窗口，保留窗口、活动内容 DOM、Tab、布局和文件草稿。隐藏的窗口不参与点击、焦点和无障碍导航。点击目标照常响应。窗口内、浮栏、右侧资源区、菜单及模态框继续处理各自的交互。点击右侧资源区不会触发自动最小化，连续打开文件时保持原窗口可见。

终端恢复优先沿用有效的上次选择，其次选中最右侧的已有终端 Tab。无本地 Tab 时，按项目或工作区分页查询并重新核对最近创建的运行终端，跳过查询期间已结束或清理的候选。无运行终端时提供新建入口，读取失败可重试。此规则取代 M2-20 的运行终端列表入口，聊天历史入口仍逐次鉴权核对目标。已显示过的终端 Tab 在当前已认证工作区内保留 xterm 画面和输出游标。最小化时保留原位的 xterm DOM，断开连接并停止续租；重开刷新终端状态并从原游标补读新增输出。首次打开或页面刷新时，在历史画面准备好后再显示。已结束 Tab 的前端屏幕与辅助回显清空，只展示终态和可用的退出信息；后端历史仍保留。

预览底栏仅显示简短的来源标识。所属 Turn 结束后，资源成果和产物显示在最终答复正文与复制、时间栏之间；没有最终答复时独立显示。
